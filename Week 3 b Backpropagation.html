Machine & Deep Learning · Week 3b

MLPs, Loss Functions & Backpropagation

A neural network is linear layers with non-linear activations in between. A hidden layer can turn XOR into a linearly separable problem. Training it needs two things: a loss that gives useful gradients, and backpropagation to compute those gradients efficiently. For the loss, maximum likelihood leads straight to cross-entropy. Backpropagation is the chain rule, applied from the loss backwards with every intermediate result reused.

0Test yourself first

Answer out loud before you read on. Each answer points to the part that explains it.

1. A linear classifier can't solve XOR. Which two ingredients does an MLP need to solve it?
A hidden layer and a non-linear activation. Without the activation, stacked linear layers collapse into one linear layer. Without a hidden layer there is nothing to transform the inputs into a space where the classes become separable. (This was a past exam question.) → Part 2
2. Sigmoid output plus squared error: why does learning almost stop exactly when a prediction is very wrong?
The gradient is $\frac{\partial L}{\partial z}=(y-t)\,\sigma'(z)$, and $\sigma'(z)\approx0$ when the sigmoid is saturated. With cross-entropy the $\sigma'$ cancels: $\frac{\partial L}{\partial z}=y-t$, which is large when you're very wrong. → Part 4
3. Does backpropagation minimise the loss?
No. Backpropagation only computes the gradients. The optimiser (gradient descent, later Adam and others) uses them to change the weights. → Part 6

1Big picture & key terms

One sentence to remember

Pick the loss by maximum likelihood, which gives cross-entropy with a sigmoid or softmax output and the gradient $\frac{\partial L}{\partial\mathbf z}=\mathbf y-\mathbf t$. Then use backprop: one backward sweep of the chain rule, from the loss to every weight, reusing every intermediate result.

2MLPs and the XOR problem previous lecture · Assignment 2

A recap. The lecture itself (MDL02.2) has its own note: Week 2a · Feed-forward networks (forward pass, parameters, the training loop, SGD, and XOR on the slides' notation). This part uses the assignments' layout, one sample per row.

Intuition

A linear layer can only draw straight boundaries, and stacking linear layers doesn't help: the result is still one linear map. Put a non-linear activation in between and the hidden layer can bend the space: it moves the points to new positions where a straight line does work. It is Week 3a's non-linear features, except that the network learns the features.

Formula: a linear layer (batch in the rows, as in the assignments)
$$Z=XW+\mathbf b,\qquad X\in\mathbb R^{N\times D_{\text{in}}},\ W\in\mathbb R^{D_{\text{in}}\times D_{\text{out}}},\ \mathbf b\in\mathbb R^{D_{\text{out}}},\ Z\in\mathbb R^{N\times D_{\text{out}}}.$$

$W_{ij}$ connects input $i$ to output $j$; the layer has $D_{\text{in}}D_{\text{out}}+D_{\text{out}}$ parameters. Why an activation is needed:

$$(XW_1+\mathbf b_1)W_2+\mathbf b_2=X\underbrace{(W_1W_2)}_{W}+\underbrace{(\mathbf b_1W_2+\mathbf b_2)}_{\mathbf b}\quad\text{: still one linear layer.}$$

An MLP alternates: $H=\phi(XW_1+\mathbf b_1)$, $Z=HW_2+\mathbf b_2$, with $\phi$ = ReLU $\max(0,z)$ or sigmoid $\sigma(z)=\frac1{1+e^{-z}}$.

3Maximum likelihood → cross-entropy loss slides 3–6 DL book 5.5 · Grosse

Intuition

Choose the parameters that make the data you actually saw as probable as possible. Equivalently: make the model's distribution look as much as possible like the data's distribution. Both views end in the same loss: the average of $-\log$(probability the model gave to what really happened).

Formula: the chain of rewrites (slides 3–5)

Training set $X=\{\mathbf x^{(1)},\dots,\mathbf x^{(m)}\}$, drawn i.i.d. from $p_{\text{data}}$; model family $p_{\text{model}}(\mathbf x;\theta)$.

$$\theta_{\text{ML}}=\arg\max_\theta p_{\text{model}}(X;\theta)\overset{\text{i.i.d.}}{=}\arg\max_\theta\prod_{i=1}^mp_{\text{model}}(\mathbf x^{(i)};\theta)\overset{\log}{=}\arg\max_\theta\sum_{i=1}^m\log p_{\text{model}}(\mathbf x^{(i)};\theta)\overset{\div m}{=}\arg\max_\theta\mathbb E_{\mathbf x\sim\hat p_{\text{data}}}\log p_{\text{model}}(\mathbf x;\theta).$$

The log turns a product of tiny numbers (which underflows) into a sum, and doesn't move the arg max. Dividing by $m$ doesn't move it either.

Dissimilarity view (slide 4): the KL divergence

$$D(\hat p_{\text{data}}\,\|\,p_{\text{model}})=\mathbb E_{\mathbf x\sim\hat p_{\text{data}}}\big[\log\hat p_{\text{data}}(\mathbf x)-\log p_{\text{model}}(\mathbf x;\theta)\big].$$

The first term doesn't depend on $\theta$; drop it and minimise $\mathbb E_{\hat p_{\text{data}}}[-\log p_{\text{model}}(\mathbf x;\theta)]$: the same as maximum likelihood. Cross-entropy (slide 5):

$$H(p_{\text{data}},p_{\text{model}})=H(p_{\text{data}})+D(p_{\text{data}}\,\|\,p_{\text{model}}).$$

So: minimise KL ⇔ minimise negative log-likelihood ⇔ minimise cross-entropy ⇔ maximise likelihood. For classification use the conditional likelihood (slide 6): $\theta_{\text{ML}}=\arg\max_\theta\sum_i\log P(y^{(i)}\mid\mathbf x^{(i)};\theta)$, and the output unit decides the exact form of the cross-entropy.

Tiny numbers: a coin

Data: heads, heads, tails. Model: $p(\text{heads})=\theta$. Likelihood $\theta^2(1-\theta)$; log-likelihood $2\ln\theta+\ln(1-\theta)$; derivative $\frac2\theta-\frac1{1-\theta}=0$ gives $\theta_{\text{ML}}=\frac23$: the observed frequency.

Cross-entropy per flip at $\theta=0.5$: $-(\frac23\ln0.5+\frac13\ln0.5)=\ln2=0.693$. Entropy of the data: $-(\frac23\ln\frac23+\frac13\ln\frac13)=0.637$. KL $=0.693-0.637=0.057$, and KL $=0$ at $\theta=\frac23$.

Slide 3's answer is easy to misread

The slide asks what $p_{\text{model}}(\mathbf x;\theta)$ is a probability over and answers "all possible parameters". For a fixed $\theta$, $p_{\text{model}}(\cdot\,;\theta)$ is a distribution over the data $\mathbf x$; $\theta$ only selects one member of the family. The likelihood $L(\theta)=p_{\text{model}}(X;\theta)$ is a function of $\theta$, not a probability distribution over $\theta$.

4Binary classification: why cross-entropy loss slides 8–14 Grosse §2

Two classes need one number, $P(Y=1\mid\mathbf x)$, because $P(Y=0\mid\mathbf x)=1-P(Y=1\mid\mathbf x)$ (slide 8). Three attempts:

  1. Clip a linear unit (slide 8): $y=\max(0,\min(1,\mathbf w^T\mathbf h+b))$. Outside $[0,1]$ the function is flat, so the gradient is 0 and gradient descent can't move.
  2. Sigmoid + squared error (slides 9–11): $z=\mathbf w^T\mathbf x+b$, $y=\sigma(z)$, $L_{\text{SE}}=\frac12(y-t)^2$. Now $\frac{\partial L}{\partial z}=(y-t)\,y(1-y)$: when the prediction is very wrong the sigmoid is saturated and the gradient vanishes (Grosse Fig. 1). And with a plain linear output, squared error punishes being "too right": for $t=1$, $y=10$ costs $\frac12\cdot81$ but $y=0$ only $\frac12$ (slide 11; compare Week 2b's widget).
  3. Sigmoid + cross-entropy = logistic regression (slides 12–14): the winner.
Formula (Grosse eq. 13, 15)
$$L_{\text{CE}}(y,t)=\begin{cases}-\log y&t=1\\-\log(1-y)&t=0\end{cases}=-t\log y-(1-t)\log(1-y),\qquad y=\sigma(z).$$

It is the negative log of the Bernoulli likelihood $y^t(1-y)^{1-t}$. In terms of the logit, for $t=1$: $L=\log(1+e^{-z})$, almost linear for very wrong $z$. The gradient:

$$\frac{\partial L_{\text{CE}}}{\partial y}=\frac{y-t}{y(1-y)},\qquad\frac{\partial L_{\text{CE}}}{\partial z}=\frac{y-t}{y(1-y)}\cdot y(1-y)=y-t.$$
Tiny numbers

$t=1$, $z=-5$: $y=\sigma(-5)=0.0067$, so the model is confidently wrong. Squared error: $\frac{\partial L}{\partial z}=(0.0067-1)\cdot0.0067\cdot0.9933=-0.0066$. Cross-entropy: $\frac{\partial L}{\partial z}=0.0067-1=-0.9933$, about 150 times larger.

In practice: compute the loss from the logits

$\sigma(z)$ can round to exactly 0 and then $\log0=-\infty$. Write the loss as a function of $z$, $L=t\log(1+e^{-z})+(1-t)\log(1+e^{z})$, as PyTorch's BCEWithLogitsLoss and CrossEntropyLoss do (Grosse §2.5).

5Multiclass: softmax and cross-entropy loss slide 15 Grosse §3

Formula (Grosse eq. 21, 23)
$$\mathbf t=(0,\dots,0,\underbrace{1}_{k},0,\dots,0),\qquad y_k=\operatorname{softmax}(\mathbf z)_k=\frac{e^{z_k}}{\sum_{k'}e^{z_{k'}}},\qquad L_{\text{CE}}=-\sum_{k=1}^Kt_k\log y_k=-\mathbf t^T\log\mathbf y.$$

Outputs are positive and sum to 1. If one $z_k$ is much larger than the rest, the softmax approximates the arg max. With two classes, $\operatorname{softmax}(z_1,z_2)_1=\sigma(z_1-z_2)$. The gradient has the same shape as in the binary case:

$$\frac{\partial L_{\text{CE}}}{\partial\mathbf z}=\mathbf y-\mathbf t.$$
Tiny numbers

$\mathbf z=(2,1,0)$: $e^{\mathbf z}=(7.389,\,2.718,\,1)$, sum $11.107$, so $\mathbf y=(0.665,\,0.245,\,0.090)$. True class 2: $L=-\ln0.245=1.408$; $\frac{\partial L}{\partial\mathbf z}=(0.665,\,-0.755,\,0.090)$. Adding the same constant to all logits changes nothing, so implementations subtract $\max_kz_k$ first to avoid overflowing $e^{z}$.

6Backpropagation: the chain rule, reused backprop slides 2–10 Grosse §2

Intuition

Gradient descent needs $\partial L/\partial w$ for every weight (slide 5: one coordinate per weight and bias in all layers). Differentiating each one separately repeats the same sub-expressions over and over. Backprop computes the derivatives backwards, from the loss to the inputs, so every intermediate result is computed once and reused: "just" a clever application of the chain rule (slide 4).

Formula: chain rule (slide 6) and the running example (slides 7–9)
$$\frac{dz}{dx}=\frac{dz}{dy}\frac{dy}{dx},\qquad\frac{d}{dt}f\big(x(t),y(t)\big)=\frac{\partial f}{\partial x}\frac{dx}{dt}+\frac{\partial f}{\partial y}\frac{dy}{dt}.$$

Model: $L=\frac12\big(\sigma(wx+b)-t\big)^2$. Done naively (slide 7), $\frac{\partial L}{\partial w}=(\sigma(wx+b)-t)\,\sigma'(wx+b)\,x$ and $\frac{\partial L}{\partial b}=(\sigma(wx+b)-t)\,\sigma'(wx+b)$ compute the same factor twice. Decompose instead: $z=wx+b$, $y=\sigma(z)$, $L=\frac12(y-t)^2$ (slide 8), and write $\bar v=\partial L/\partial v$ (bar notation, slide 9):

$$\bar y=y-t,\qquad\bar z=\bar y\,\sigma'(z),\qquad\bar w=\bar z\,x,\qquad\bar b=\bar z.$$

Four unique terms, in dependency order from the loss backwards. Then gradient descent: $w^*=w-\epsilon\,\bar w$, $b^*=b-\epsilon\,\bar b$.

Tiny numbers (slide 10, a likely exam format)

$x=2$, $w=3$, $b=4$, $t=5$, $\sigma(z)=\max\{0,z\}$ (ReLU), learning rate $0.1$.

  • Forward: $z=3\cdot2+4=10$, $y=10$, $L=\frac12(10-5)^2=12.5$.
  • Backward: $\bar y=10-5=5$, $\bar z=5\cdot1=5$ (ReLU slope is 1 since $z>0$), $\bar w=5\cdot2=10$, $\bar b=5$.
  • Update: $w^*=3-0.1\cdot10=2$, $b^*=4-0.1\cdot5=3.5$.
  • Check: $y=2\cdot2+3.5=7.5$, $L=\frac12(2.5)^2=3.125$: the loss dropped from 12.5.
Backprop ≠ gradient descent (slide 2's first learning goal)

Backpropagation is an algorithm to compute gradients. Gradient descent is an algorithm to use them: step against the gradient. You can backprop without updating (e.g. to inspect gradients), and you can update with gradients from elsewhere (e.g. finite differences, which are far too slow for real networks).

7Computational graphs and the general algorithm backprop slides 11–14 Grosse §2.4

Formula: backprop on any graph (slide 12)

A node is a variable (scalar, vector, tensor); an arrow $u\to v$ means $v$ is computed from $u$. Number the nodes in a topological order (every parent before its children), with the loss last as $n_N$.

  1. Forward pass: for $i=1,\dots,N$: compute $n_i$ from its parents.
  2. Backward pass: $\bar n_N=1$ (the derivative of a node with respect to itself); then for $i=N-1,\dots,1$:
$$\bar n_i=\sum_{n_j\in\text{Children}(n_i)}\bar n_j\,\frac{\partial n_j}{\partial n_i}.$$

A node only needs gradients from its children: that is the multivariate chain rule, summing over all paths.

The regularised example (slide 13)

Forward: $z=wx+b$, $y=\sigma(z)$, $L=\frac12(y-t)^2$, $R=\frac12w^2$, $L_{\text{reg}}=L+\lambda R$. Topological order: $(w,b,x,z,y,t,L,R,L_{\text{reg}})$. Backward:

$$\bar L_{\text{reg}}=1,\quad\bar R=\bar L_{\text{reg}}\lambda,\quad\bar L=\bar L_{\text{reg}},\quad\bar y=\bar L\,(y-t),\quad\bar z=\bar y\,\sigma'(z),\quad\bar w=\bar z\,x+\bar R\,w,\quad\bar b=\bar z.$$

$w$ has two children ($z$ and $R$), so $\bar w$ is a sum of two terms. Forgetting the regulariser's term is the classic mistake.

8Backprop for a whole layer: matrices and shapes Assignment 3 Grosse §3

Intuition

A network is a chain of modules (Linear, ReLU, Sigmoid, loss). Each module only needs two functions: forward, which also caches what the backward pass will need, and backward, which receives the upstream gradient $\partial L/\partial(\text{output})$, multiplies it by its own local derivative, and returns the downstream gradient $\partial L/\partial(\text{input})$. The network's backward pass just calls them in reverse order.

Formula: the modules of Assignment 3 (batch in the rows)
$$\textbf{Linear } Z=XW+\mathbf b:\qquad\bar W=X^T\bar Z,\qquad\bar{\mathbf b}=\textstyle\sum_{n}\bar Z_{n,:},\qquad\bar X=\bar ZW^T.$$ $$\textbf{ReLU } H=\max(0,Z):\ \ \bar Z=\bar H\odot\mathbb 1[Z>0]\qquad\textbf{Sigmoid } H=\sigma(Z):\ \ \bar Z=\bar H\odot H\odot(1-H)$$ $$\textbf{MSE } L=\tfrac1{\#}\textstyle\sum(P-T)^2:\ \ \bar P=\tfrac2{\#}(P-T)\qquad\textbf{softmax+CE (mean over }N):\ \ \bar Z=\tfrac1N(Y-T)$$

$\#$ is the number of entries the mean runs over (numel); $\odot$ is element-wise multiplication. Grosse writes the same with column vectors: $\bar{\mathbf W}=\bar{\mathbf z}\mathbf h^T$, $\bar{\mathbf h}=\mathbf W^T\bar{\mathbf z}$.

  • Why $\bar{\mathbf b}$ sums over the batch: the same $\mathbf b$ is added to every row, so it has $N$ children; their gradients add up (the multivariate chain rule again).
  • Why the hidden layer needs $W^T$: every hidden unit feeds every output, so its gradient sums over all outputs: $\bar h_i=\sum_k\bar z_kW_{ik}$. That sum is the product with $W^T$ (Grosse calls it the only step that really uses the multivariate chain rule).
  • Cost: one backward pass costs about as much as a couple of forward passes, for all parameters at once (reverse-mode differentiation). Finite differences, $\frac{f(\theta+\epsilon)-f(\theta-\epsilon)}{2\epsilon}$, need two forward passes per parameter, which makes them only useful to check a backward pass (gradient checking).
In code: a two-layer network in the assignment style (basic tensor ops only)
# forward (cache what backward needs)
Z1 = X @ W1 + b1          # (N, H)
H1 = Z1.clamp(min=0)      # ReLU
Z2 = H1 @ W2 + b2         # (N, K) logits
# loss gradient: softmax + cross-entropy, averaged over N
Y  = torch.softmax(Z2, dim=1)          # or your own Softmax
dZ2 = (Y - T) / N
# backward, in reverse order
dW2 = H1.T @ dZ2;  db2 = dZ2.sum(dim=0);  dH1 = dZ2 @ W2.T
dZ1 = dH1 * (Z1 > 0).float()
dW1 = X.T @ dZ1;   db1 = dZ1.sum(dim=0)
# gradient descent
W1 -= lr * dW1;  b1 -= lr * db1;  W2 -= lr * dW2;  b2 -= lr * db2

9Saturation and vanishing gradients Assignment 3 A2.5

Backprop multiplies by one activation derivative per layer. For the sigmoid that factor is at most 0.25 and close to 0 when a unit is saturated. In Assignment 3 the XOR network with sigmoid units first learns quickly, then stalls long before 100% accuracy: the gradients have become tiny. Across many layers it gets worse: ten sigmoid layers multiply the gradient by at most $0.25^{10}\approx10^{-6}$. That is the vanishing gradient problem.

  • ReLU passes gradient 1 for every active unit, which is a big reason it is the default hidden activation.
  • At the output, cross-entropy cancels the sigmoid's or softmax's own derivative (Part 4), so pair those outputs with cross-entropy, not MSE.
  • Week 4a adds more fixes: better initialisation, normalisation and adaptive optimisers.

10Handwriting blueprint

Write each step on paper first, then reveal it.

1 · From the Bernoulli likelihood to $L_{\text{CE}}$

  1. The model says $P(t=1\mid\mathbf x)=y$, so $P(t\mid\mathbf x)=y^t(1-y)^{1-t}$ for $t\in\{0,1\}$.
  2. Over i.i.d. examples: $\prod_iy_i^{t_i}(1-y_i)^{1-t_i}$.
  3. Take $-\log$: $\sum_i\big[-t_i\log y_i-(1-t_i)\log(1-y_i)\big]$.
  4. Each term is $L_{\text{CE}}(y_i,t_i)$: maximising the likelihood = minimising the summed cross-entropy.

2 · $\partial L_{\text{CE}}/\partial z=y-t$ for a sigmoid output

  1. $\sigma(z)=(1+e^{-z})^{-1}$, so $\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\sigma(z)\,(1-\sigma(z))=y(1-y)$.
  2. $\frac{\partial L}{\partial y}=-\frac ty+\frac{1-t}{1-y}=\frac{-t(1-y)+(1-t)y}{y(1-y)}=\frac{y-t}{y(1-y)}$.
  3. Chain rule: $\frac{\partial L}{\partial z}=\frac{\partial L}{\partial y}\frac{dy}{dz}=\frac{y-t}{y(1-y)}\cdot y(1-y)=y-t$.
  4. Compare squared error: $\frac{\partial L_{\text{SE}}}{\partial z}=(y-t)\,y(1-y)$, which keeps the factor that vanishes.

3 · Softmax + cross-entropy: $\partial L/\partial z_j=y_j-t_j$

  1. $L=-\sum_kt_k\log y_k$ with $\log y_k=z_k-\log\sum_{k'}e^{z_{k'}}$.
  2. So $L=-\sum_kt_kz_k+\big(\sum_kt_k\big)\log\sum_{k'}e^{z_{k'}}$, and $\sum_kt_k=1$.
  3. $\frac{\partial}{\partial z_j}\log\sum_{k'}e^{z_{k'}}=\frac{e^{z_j}}{\sum_{k'}e^{z_{k'}}}=y_j$.
  4. $\frac{\partial L}{\partial z_j}=-t_j+y_j$. In vector form: $\bar{\mathbf z}=\mathbf y-\mathbf t$.

4 · Backprop on a graph, by hand

  1. Draw the graph and write a topological order; mark nodes with two or more children.
  2. Forward: compute every node's value in that order and write it next to the node.
  3. Set the loss's bar to 1.
  4. Go through the nodes in reverse order: bar = Σ over children of (child's bar × local derivative ∂child/∂node), evaluated with the forward values.
  5. Read off the parameter bars and apply $\theta\leftarrow\theta-\epsilon\,\bar\theta$; recompute the loss to check that it went down.

5 · The backward pass of a linear layer

  1. Forward: $Z=XW+\mathbf b$; cache $X$. Shapes: $X$ $(N,D_{\text{in}})$, $W$ $(D_{\text{in}},D_{\text{out}})$, $Z$ $(N,D_{\text{out}})$.
  2. Element-wise: $Z_{nj}=\sum_iX_{ni}W_{ij}+b_j$, so $\frac{\partial Z_{nj}}{\partial W_{ij}}=X_{ni}$.
  3. Sum over every place $W_{ij}$ appears: $\bar W_{ij}=\sum_n\bar Z_{nj}X_{ni}$, i.e. $\bar W=X^T\bar Z$.
  4. Similarly $\bar X_{ni}=\sum_j\bar Z_{nj}W_{ij}$, i.e. $\bar X=\bar ZW^T$; and $\bar b_j=\sum_n\bar Z_{nj}$.
  5. Check the shapes: $\bar W$ $(D_{\text{in}},D_{\text{out}})$, $\bar X$ $(N,D_{\text{in}})$, $\bar{\mathbf b}$ $(D_{\text{out}})$.

11Exam traps

Watch out
  • XOR needs both a hidden layer and a non-linear activation (24/25 exam). Linear layers without activations collapse into one.
  • Backprop computes gradients; it does not update anything. Gradient descent (or another optimiser) does the update.
  • Maximum likelihood ⇔ minimum KL ⇔ minimum cross-entropy ⇔ minimum NLL: same arg min, different values (the entropy term is a constant). So "there is a dissimilarity measure equivalent to maximum likelihood" is TRUE (24/25 exam).
  • The i.i.d. assumption is what turns the joint likelihood into a product (slide 3).
  • Sigmoid + squared error has vanishing gradients on confident mistakes; sigmoid + cross-entropy gives $y-t$.
  • $\partial L/\partial\mathbf z=\mathbf y-\mathbf t$ for sigmoid + binary CE and for softmax + CE. If an exam derivation takes a page, you missed this shortcut.
  • A node with two children sums two gradient terms (e.g. $\bar w=\bar zx+\bar R\,w$ with weight decay).
  • Bias gradient = sum over the batch, not the mean (unless the loss itself is a mean, in which case the $1/N$ is already in $\bar Z$).
  • Every gradient has the shape of its variable: $\bar W=X^T\bar Z$, never $\bar ZX^T$ in the row convention.
  • MSE's gradient divides by the number of entries: $\frac2{\#}(P-T)$; with one-hot targets of $K$ classes that is $N\cdot K$, not $N$.
  • ReLU's derivative is 0 for negative inputs: a unit that is negative for every input stops learning.
  • Softmax is invariant to adding a constant to all logits; subtract the maximum before exponentiating.
  • Slide 10 uses $\sigma=\max(0,z)$, so $\sigma'(10)=1$. Don't plug in the sigmoid by reflex.

1. past exam True or false: there exists a dissimilarity measure between the data and model distributions that is equivalent to maximising the log-likelihood.
True. The KL divergence $D(\hat p_{\text{data}}\,\|\,p_{\text{model}})$ (equivalently the cross-entropy): minimising it gives the same $\theta$ as maximum likelihood, because it differs from the negative log-likelihood only by the data entropy, which doesn't depend on $\theta$.
2. past exam Which statement about an MLP solving XOR is correct?
Both a hidden layer and non-linear activation functions are necessary. See the folding picture in Part 2.
3. Slide 13 with numbers: $x=1$, $w=2$, $b=-1$, $t=3$, $\sigma=$ ReLU, $\lambda=0.5$, learning rate 0.1. Do the forward pass, all bars, one update, and the new $L_{\text{reg}}$.
Forward: $z=1$, $y=1$, $L=\frac12(1-3)^2=2$, $R=\frac12\cdot4=2$, $L_{\text{reg}}=2+0.5\cdot2=3$. Backward: $\bar L_{\text{reg}}=1$, $\bar R=0.5$, $\bar L=1$, $\bar y=y-t=-2$, $\bar z=-2\cdot1=-2$, $\bar w=\bar zx+\bar Rw=-2+1=-1$, $\bar b=-2$. Update: $w=2+0.1=2.1$, $b=-1+0.2=-0.8$. New: $z=y=1.3$, $L=\frac12(1.7)^2=1.445$, $R=\frac12\cdot2.1^2=2.205$, $L_{\text{reg}}=1.445+1.1025=2.5475<3$ ✓. (Check it in the stepper widget.)
4. Logits $\mathbf z=(1,1,1)$ and true class 3. What are $\mathbf y$, $L$ and $\partial L/\partial\mathbf z$?
$\mathbf y=(\frac13,\frac13,\frac13)$, $L=\ln3=1.099$, $\partial L/\partial\mathbf z=(\frac13,\frac13,-\frac23)$.
5. How many parameters does the MLP 2 → 4 → 4 → 1 (with biases) have?
$(2\cdot4+4)+(4\cdot4+4)+(4\cdot1+1)=12+20+5=37$.
6. $t=0$ and the network outputs $y=\sigma(z)=0.9$. Give the squared-error and the cross-entropy gradient with respect to $z$.
SE: $(y-t)\,y(1-y)=0.9\cdot0.9\cdot0.1=0.081$. CE: $y-t=0.9$: eleven times larger.
7. Why does the sum over a batch in $\bar{\mathbf b}$ follow from the backprop algorithm itself?
$\mathbf b$ is used in every row of $Z$, so in the graph it has one child per example. The backprop rule sums over children: $\bar b_j=\sum_n\bar Z_{nj}\cdot1$.
8. You have $10^7$ weights. How many forward passes does a central finite-difference gradient need, and how many does backprop need?
Finite differences: $2\times10^7$ forward passes. Backprop: one forward and one backward pass, roughly the cost of 2–3 forward passes.

def forward(self, x):

past exam Task D + E · MSE with gradient, and the training loop

Return (loss, dloss_dpred) for $\text{loss}=\frac1N\sum_i(p_i-t_i)^2$; then train with forward, loss, backward through all layers and plain SGD for 5 epochs, recording the average loss per epoch.

Show answer
def mse_loss_and_grad(pred, target):
    diff = pred - target
    return float((diff ** 2).mean()), 2.0 * diff / pred.numel()

def train(model, batches_x, batches_y, lr=0.1, epochs=5):
    losses_per_epoch = []
    for epoch in range(epochs):
        total = 0.0
        for x, y in zip(batches_x, batches_y):
            pred = model.forward(x)
            loss, d = mse_loss_and_grad(pred, y)
            total += loss
            d = model.l3.backward(d)
            d = model.l2.backward(relu_backward(model.z2, d))
            model.l1.backward(relu_backward(model.z1, d))
            for layer in (model.l1, model.l2, model.l3):
                layer.weight -= lr * layer.weight_grad
                layer.bias -= lr * layer.bias_grad
        losses_per_epoch.append(total / len(batches_x))
    return losses_per_epoch

With targets of shape (N, 1), pred.numel() equals $N$, matching the task's $\frac2N(p_i-t_i)$. The order matters: relu_backward needs the pre-activation $z$ of the same layer.

past exam ELU forward (24/25)

Implement $F(x)=x$ for $x\ge0$, $\alpha(e^x-1)$ otherwise.

Show answer
def elu(x, alpha=0.5):
    return torch.where(x >= 0, x, alpha * (torch.exp(x) - 1))

The review's answer, x[x < 0] = (alpha * (torch.exp(x) - 1))[x < 0]; return x, gives the same numbers but overwrites the input tensor in place. That is risky if x is still needed (for example cached for a backward pass).

past exam Huber loss and its derivative (24/25)

Quadratic for small errors, linear for large ones: $L=\frac12e^2$ if $|e|\le\delta$, else $\delta|e|-\frac12\delta^2$, with $e=y_{\text{true}}-y_{\text{pred}}$. Return the loss and $\partial L/\partial y_{\text{pred}}$.

Show answer
def huber(y_true, y_pred, delta=1.0):
    e = y_true - y_pred
    small = e.abs() <= delta
    loss = torch.where(small, 0.5 * e ** 2, delta * e.abs() - 0.5 * delta ** 2)
    grad = torch.where(small, -e, -delta * torch.sign(e))   # d/d y_pred: note the minus
    return loss, grad

The minus sign comes from $e=y_{\text{true}}-y_{\text{pred}}$: $\frac{\partial}{\partial y_{\text{pred}}}\frac12e^2=-e$. The two pieces meet at $|e|=\delta$ with the same value and slope, so large errors get a constant gradient $\pm\delta$, which is robust to outliers (unlike MSE).
