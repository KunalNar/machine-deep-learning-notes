Bayes decision theory and errors Week 1a

24/25 #4
True or false: with feature vector $\mathbf x$ and class $\omega$, Bayes' rule states $p(\omega\mid\mathbf x)=p(\mathbf x\mid\omega)p(\omega)/p(\mathbf x)$.
True. Posterior = likelihood × prior / evidence. → Week 1a §4
24/25 #6
True or false: the Bayes error is always smaller than or equal to the estimated true error (sufficient data).
True. No classifier can do better than the Bayes classifier. → Week 1a §5
24/25 #8
True or false: in 0 dimensions the classification error is always 0.5.
False. Without features you always predict the most probable class: error $1-\max_kp(\omega_k)$, which is 0.5 only for two equally likely classes. → Week 1a §5
24/25 #2
True or false: with feature extraction any multidimensional problem can, in principle, be reduced to one dimension without increasing the Bayes error.
True. For example, map $\mathbf x$ to its posterior $p(\omega_1\mid\mathbf x)$: that single number is all the Bayes classifier needs (two classes). → Week 1a §4
24/25 #1 · 2025 MC 2
An imbalanced data set where misclassifying the minority class costs more: an effective strategy using Bayes' rule?
Give the minority class a higher weight (cost): the minimum-risk rule moves the boundary so that fewer expensive mistakes are made. → Week 1a §6
24/25 #19
1-D, four classes, equal priors, class-conditional densities given in a figure: (a) the priors, (b) the decision boundaries, (c) the Bayes error.
(a) $\frac14$ each. (b) Where the largest density changes; the review gives $x=1,2,2.5,3.5,4$. (c) Add the areas of the wrongly decided parts, each times $\frac14$; the review gives $0.25\cdot[\frac12+\frac14\cdot2]$. The figure is not in the review; practise with the four-class variant in Week 1a. → Week 1a: four classes

Density-based classifiers Week 1b

24/25 #10 · 2025 MC 3
The covariance matrix of a 2-D Gaussian controls…
…the spread and the orientation of the distribution (the axes of its ellipses). → Week 1b §3
24/25 #5
True or false: given enough training data, QDA finds a classifier at least as good as LDA, even if the true decision boundary is linear.
False (review answer). A linear boundary does not mean the classes are Gaussian with equal covariances; QDA estimates far more parameters, so "at least as good" is not guaranteed. → Week 1b §8
24/25 #7
True or false: even if the Bayes classifier is non-linear, the nearest mean classifier may still outperform k-NN.
True. With few training objects a simple, biased classifier can beat a flexible one (bias–variance). → Week 1b §8
24/25 #17
Which statement about the k-NN classifier is correct?
With $k=n$ the accuracy equals the prior of the largest class: every object gets the majority label. → Week 1b §11
24/25 #3
True or false: for LDA, optimising a scaling factor $s_i$ per feature cannot improve the performance (sufficient data).
True. LDA is invariant to rescaling features; k-NN, Parzen and nearest mean are not. → Week 1b §12
24/25 #21
Four 2-D objects from two classes: where is the LDA boundary, and what happens with QDA?
LDA: a straight line halfway between the class means (perpendicular to the direction set by $\Sigma^{-1}$). QDA: the per-class covariance matrices are singular, so QDA is not defined. → Week 1b: LDA and QDA on four objects
2025 MC 4

Linear classifiers Week 2b

24/25 #9
True or false: in three dimensions the perceptron can perfectly separate any configuration of five points from two classes.
False. A linear classifier in $p$ dimensions shatters at most $p+1=4$ points. → Week 2b §13
24/25 #11
Which claim about the Fisher classifier and the linear discriminant classifier is correct?
Fisher maximises the separation of the projected classes; LDA does not (it assumes Gaussians with equal covariance). Both end up with the same direction. → Week 2b §5
