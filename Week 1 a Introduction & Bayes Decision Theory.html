Machine & Deep Learning · Week 1a

Introduction & Bayes Decision Theory

Machine learning is learning from examples. This lecture builds the ideal classifier: for an object with features $\mathbf x$, work out how likely each class is (the posterior), pick the most likely one, and accept that some error, the Bayes error, can never be removed. Unequal costs and a reject option only move the threshold; the model stays the same.

0Test yourself first

Answer out loud before you read on. Rough is fine; each answer points to the part that explains it.

1. For an object with feature value $x$ you know $p(x\mid\omega_1)$, $p(x\mid\omega_2)$ and the priors. Which class do you pick, in one sentence?
The class with the largest posterior $P(\omega_i\mid x)$. Since $p(x)$ is the same for every class, that is the class with the largest $p(x\mid\omega_i)\,P(\omega_i)$. → Part 4
2. Could a huge neural network trained on a billion examples get below the Bayes error?
No. The Bayes error comes from the overlap of the true class distributions: the same $x$ really occurs in both classes, so whatever you decide there is sometimes wrong. More data and better models only bring you closer to it. → Part 5
3. Sending an ill patient home is 10× worse than treating a healthy one. Which decision region grows, and does the model change?
The "ill" region grows: you already say "ill" once $P(\text{ill}\mid x)$ passes about 0.09. The model (the posteriors) stays the same; only the threshold you compare them with moves. → Part 6

1Big picture & key terms

The lecture is one argument in five steps. Each step answers the question the previous one raises.

1. RepresentMeasure each object; its features form a vector $\mathbf x$, a point in feature space. §2–3
→
2. Ask the right questionFor every $\mathbf x$: how likely is each class? That's the posterior $p(y\mid\mathbf x)$. §3
→
3. Bayes' ruleBuild the posterior from class densities $p(\mathbf x\mid y)$ and priors $p(y)$. §4
→
4. Decide & scorePick the largest posterior. What's left over is the Bayes error $\varepsilon^*$. §5
→
5. CostsUnequal mistakes: weigh the posteriors by their costs before comparing. §6–7
One sentence to remember

Pick the class with the largest posterior (with costs: the smallest expected cost). No classifier, however clever, beats the Bayes error.

2Learning from examples: the pipeline slides 1–18

Finding the cat in a photo, recognising a place or a face: easy for people, very hard to write down as rules. Pattern recognition learns such tasks from examples instead (slides 2–6).

  • Features turn an object into numbers. Good features keep the classes apart; noisy measurements and poor features make them overlap (slides 14–15).
  • Labels come from outside, usually from an expert (slide 13). Always ask: is the label really determined by the measurements, and what is the ground truth? Sometimes even experts disagree ("healthy or diseased?", slide 15).
  • Test on independent data (slides 16–18). On slide 17 you guess "cat or green bean?" only because those were the earlier examples: that is overfitting to the training data. A fair test uses objects the classifier has not seen.
Why this matters later

The error measured on the training set (the apparent error) is too optimistic. You'll meet it again in Week 4b (evaluation) and Week 5 (complexity and overfitting).

3Feature space and the classifier's job slides 25–32

Put the $p$ measurements of an object in a vector $\mathbf x=(x_1,\dots,x_p)$. Every object is now a point in a $p$-dimensional feature space. Where the points of each class lie is described by a probability density over that space, $p(\mathbf x, y)$ (slide 25).

What the model should give you (slides 30–31)

Ideally, for every $\mathbf x$, the posterior $p(y\mid\mathbf x)$: "given these features, how likely is each class?". In practice you only get an estimate $\hat p(y\mid\mathbf x)$, or you fit a function $f(\mathbf x)$ that makes the decision directly. The rule itself is simple:

$$\text{assign }\mathbf x\text{ to } y_1 \text{ if } p(y_1\mid\mathbf x) > p(y_2\mid\mathbf x),\ \text{ otherwise to } y_2.$$

Four ways to write the same two-class rule (slide 32)

Assign $y_1$ if …Why you'd write it this way
$p(y_1\mid\mathbf x) > p(y_2\mid\mathbf x)$The definition.
$p(y_1\mid\mathbf x) - p(y_2\mid\mathbf x) > 0$A discriminant function $f(\mathbf x)>0$: the form linear classifiers use (Week 2b).
$\dfrac{p(y_1\mid\mathbf x)}{p(y_2\mid\mathbf x)} > 1$A ratio. Costs simply replace the "1" by another number (Part 6).
$\log p(y_1\mid\mathbf x) - \log p(y_2\mid\mathbf x) > 0$Logs turn Gaussian products into sums: that's how linear and quadratic boundaries appear (Week 1b).
Why they agree

Subtracting, dividing by a positive number and taking logs never change which side is larger. So all four rules carve out exactly the same regions. Exam questions like to swap between these forms.

4Bayes' rule: from class densities to posteriors slides 33–39 Bishop §1.2

Intuition

The posterior "is this object an apple?" is hard to estimate directly. It is often easier to describe each class on its own: what do apples look like ($p(\mathbf x\mid\text{apple})$) and how common are apples ($p(\text{apple})$). Bayes' rule turns those two into the posterior.

Formula
$$p(y_i\mid\mathbf x)=\frac{p(\mathbf x\mid y_i)\,p(y_i)}{p(\mathbf x)},\qquad p(\mathbf x)=\sum_{j=1}^{C}p(\mathbf x\mid y_j)\,p(y_j)$$

$p(y_i)$: prior · $p(\mathbf x\mid y_i)$: class density (likelihood) · $p(\mathbf x)$: evidence, the same for every class · $p(y_i\mid\mathbf x)$: posterior · $C$: number of classes. The right-hand formula is the law of total probability (slide 37): you never have to estimate $p(\mathbf x)$ separately.

Both come from the two rules of probability (Bishop §1.2): the sum rule $p(\mathbf x)=\sum_y p(\mathbf x,y)$ and the product rule $p(\mathbf x,y)=p(\mathbf x\mid y)\,p(y)=p(y\mid\mathbf x)\,p(\mathbf x)$. Divide the product rule by $p(\mathbf x)$ and you have Bayes' rule.

Tiny numbers: Bishop's fruit boxes

A red box holds 2 apples and 6 oranges, a blue box 3 apples and 1 orange. You pick the red box 40% of the time. Someone hands you an orange. Which box did it come from?

Seeing the fruit raised the belief in the red box from the prior 0.40 to the posterior 0.67. Classifying an object is the same calculation: box ↔ class, fruit ↔ feature value.

Two things people get wrong
  • You don't need $p(\mathbf x)$ to decide. It is the same for all classes, so comparing $p(\mathbf x\mid y_i)\,p(y_i)$ gives the same answer. You only need $p(\mathbf x)$ to turn those into actual probabilities.
  • $p(\mathbf x\mid y)$ is a density over $\mathbf x$, not the probability of a class. It can be larger than 1: the triangle in Exercise 1.3 has height 1, and a Gaussian with $\sigma=0.1$ peaks at about 4. Only the posterior is a probability of the class.
In code
import numpy as np
from scipy.stats import norm

x  = np.array([-1.0, 0.5, 1.5, 3.0])
p1, p2 = 0.75, 0.25                          # priors p(y1), p(y2)
j1 = norm.pdf(x, loc=0, scale=1) * p1        # p(x|y1) p(y1)
j2 = norm.pdf(x, loc=2, scale=1) * p2        # p(x|y2) p(y2)
px = j1 + j2                                 # evidence: law of total probability
post1 = j1 / px                              # posterior p(y1|x)
pred = np.where(j1 > j2, 1, 2)               # Bayes decision: p(x) not needed
print(post1.round(3), pred)                  # [0.994 0.891 0.525 0.052] [1 1 1 2]

Look at $x=1.5$: it is closer to the class-2 mean, yet goes to class 1, because class 1 is three times as common. The boundary moved from 1 to 1.549 (blueprint 1 shows why).

5Classification error and the Bayes error slides 40–44 Bishop §1.5.1

Intuition

Where the scaled class densities overlap, the same $\mathbf x$ comes from both classes. Whatever you decide there, some of the objects with that $\mathbf x$ belong to the other class. Those mistakes cannot be avoided. Mistakes you can avoid come only from putting the boundary in the wrong place.

Formula
$$p(\text{error})=\sum_{i=1}^{C}p(\text{error}\mid y_i)\,p(y_i)=\int_{\Omega_2}p(\mathbf x\mid y_1)\,p(y_1)\,d\mathbf x+\int_{\Omega_1}p(\mathbf x\mid y_2)\,p(y_2)\,d\mathbf x$$

$\Omega_i$: the region where you predict $y_i$. The first integral counts class-1 objects that land in $\Omega_2$ ("$\mathbf x\in y_1,\ \mathbf x\to y_2$" on slide 42), the second the reverse.

The Bayes classifier keeps the larger term at every $\mathbf x$, so it pays only the smaller one:

$$\varepsilon^*=\int\min\big(p(\mathbf x\mid y_1)\,p(y_1),\;p(\mathbf x\mid y_2)\,p(y_2)\big)\,d\mathbf x \qquad\Big(C\text{ classes: }\ \varepsilon^*=1-\int\max_i\,p(\mathbf x\mid y_i)\,p(y_i)\,d\mathbf x\Big)$$
Tiny numbers (Exercise 1.1a)

$\mu_1=0$, $\mu_2=1$, $\sigma^2=\tfrac12$, equal priors. The boundary is the midpoint $x^*=0.5$, and by symmetry both error pieces are equal:

$$\varepsilon^*=2\cdot\tfrac12\cdot P(x>0.5\mid y_1)=\Phi\!\Big(\!-\frac{0.5}{\sqrt{0.5}}\Big)=\Phi(-0.707)\approx 0.240 .$$

($\Phi$ is the standard normal CDF.) Move the boundary to $x_b=0$ and the error grows to $0.289$: the extra $0.049$ is the hatched wedge.

Four facts about the Bayes error (slide 44)

  • It is the minimum attainable error, and typically larger than 0.
  • It depends on the data distribution, not on the classifier you choose.
  • You can't compute it in practice: you don't know the true class densities, and in high dimensions the integrals are very hard.
  • Any real classifier has a true error $\ge\varepsilon^*$. Better density estimates move you towards $\varepsilon^*$, never below it.

6Misclassification costs and minimum risk slides 45–52 Bishop §1.5.2

Intuition

Not all mistakes are equal. Calling an ill patient healthy sends them home untreated; calling a healthy person ill costs an extra test. Give each kind of mistake a price, then at every $\mathbf x$ choose the class whose expected price is lowest.

Formula

Cost $\lambda_{ji}$: the price of assigning an object of true class $y_j$ to class $y_i$, with $\lambda_{ii}=0$.

Conditional risk of choosing $y_i$ at $\mathbf x$ (slide 47): $\;l^i(\mathbf x)=\sum_{j=1}^{C}\lambda_{ji}\,p(y_j\mid\mathbf x)$

Overall risk: $\;r=\sum_{i=1}^{C}\int_{\Omega_i}l^i(\mathbf x)\,p(\mathbf x)\,d\mathbf x$. It is smallest when every $\mathbf x$ goes to the class with the smallest $l^i(\mathbf x)$ (slide 48).

Two classes (slide 50): assign $y_1$ if

$$\lambda_{21}\,p(y_2\mid\mathbf x)\;<\;\lambda_{12}\,p(y_1\mid\mathbf x)\quad\Longleftrightarrow\quad\frac{p(\mathbf x\mid y_1)}{p(\mathbf x\mid y_2)}\;>\;\frac{\lambda_{21}\,p(y_2)}{\lambda_{12}\,p(y_1)}$$

With $\lambda_{12}=\lambda_{21}=1$ (the 0/1 loss) this is exactly the Bayes rule of Part 5: risk = error.

Tiny numbers (slide 46)

$\lambda_{\text{healthy},\text{ill}}=10$ and $\lambda_{\text{ill},\text{healthy}}=100$. At some $\mathbf x$ the posteriors are $P(\text{ill}\mid\mathbf x)=0.2$ and $P(\text{healthy}\mid\mathbf x)=0.8$.

DecisionExpected cost $l^i(\mathbf x)$
say "healthy"$\lambda_{\text{ill},\text{healthy}}\cdot P(\text{ill}\mid\mathbf x)=100\times0.2=20$
say "ill"$\lambda_{\text{healthy},\text{ill}}\cdot P(\text{healthy}\mid\mathbf x)=10\times0.8=\mathbf 8$ ← choose this

You say "ill" although "healthy" is four times more likely. In general you say "ill" as soon as $P(\text{ill}\mid\mathbf x)>\frac{10}{10+100}\approx0.09$.

Convention trap

The slides (and Bishop's $L_{kj}$) put the true class in the rows and the decision in the columns: $\lambda_{ji}$ = true $j$, decided $i$. Some books (Duda & Hart) and your old Assignment 1 note use the opposite: rows = decision. With the matrix of Exercise 1.2 the two readings give boundaries 0.153 and 0.847. In the exam, write down which convention you use.

Minimum risk ≠ minimum error

With unequal costs the risk goes down but the number of mistakes goes up. In Exercise 1.2(a) the risk drops from 0.180 to 0.161 while the error rises from 0.240 to 0.265: you make more cheap mistakes to avoid expensive ones.

7The reject option Bishop §1.5.3 preview of Week 4b

Intuition

Near the boundary both posteriors are close to 0.5, so the classifier is basically guessing. If a human can look at those cases, let the classifier say "I don't know".

Formula
$$\text{reject }\mathbf x\ \text{ if }\ \max_i\,p(y_i\mid\mathbf x)<\theta,\qquad\text{otherwise assign }\arg\max_i p(y_i\mid\mathbf x).$$

$\theta=1$: reject everything. $\theta\le 1/C$: reject nothing, which is the plain Bayes rule. For two classes the interesting range is $0.5<\theta<1$.

  • Combining models trained on different feature sets.

9Reading extras Bishop §1.2, §1.4

Densities, expectations and covariance (§1.2.1–1.2.3)

  • A density satisfies $p(x)\ge0$ and $\int p(x)\,dx=1$. The probability of an interval is an area: $P(a<x<b)=\int_a^b p(x)\,dx$.
  • Expectation: $\mathbb E[f]=\int p(x)f(x)\,dx\approx\frac1N\sum_{n=1}^{N}f(x_n)$ with $N$ samples.
  • Variance: $\operatorname{var}[x]=\mathbb E[(x-\mathbb E[x])^2]=\mathbb E[x^2]-\mathbb E[x]^2$.
  • Covariance: $\operatorname{cov}[x,y]=\mathbb E[xy]-\mathbb E[x]\,\mathbb E[y]$; for a vector, $\Sigma=\mathbb E[(\mathbf x-\boldsymbol\mu)(\mathbf x-\boldsymbol\mu)^T]$. You need $\Sigma$ for the Gaussian classifiers of Week 1b.
  • Frequentist vs Bayesian (§1.2.3): a frequentist treats parameters $\mathbf w$ as fixed unknowns and estimates them by maximum likelihood; a Bayesian puts a prior on them and computes $p(\mathbf w\mid\mathcal D)\propto p(\mathcal D\mid\mathbf w)\,p(\mathbf w)$. The same Bayes' rule, applied to parameters instead of classes.

The curse of dimensionality (§1.4)

The consequence for classification: estimating a density by counting needs exponentially many points, so with a fixed data set, adding features can make a classifier worse. Week 1b works this out with the slides ("data in the tails") and the exam asks about it.

10The lecturer's questions slide 53

True or not: when you can estimate the posterior probabilities better, you can decrease the Bayes error.
Not true. The Bayes error is fixed by the true distributions. Better estimates lower your classifier's error and bring it closer to $\varepsilon^*$, but $\varepsilon^*$ itself doesn't move.
Give an estimate of the classification error for the apple/pear data on the slide.
Count the objects on the wrong side of the boundary (the thick $p(\omega_2\mid\mathbf x)=0.5$ contour) and divide by the total number of objects. On the slide only a handful of the roughly 100 points are on the wrong side, so a few percent.
Will that estimate be larger than, equal to, or smaller than the Bayes error?
It can be either: it is a count on a finite sample, so it scatters around the true error. If the boundary is the true Bayes boundary, the count scatters around $\varepsilon^*$. If the boundary was fitted on these same points, the count is optimistic (the apparent error) and tends to come out below the true error, possibly even below $\varepsilon^*$.
What happens when $p(y_1)=2p(y_2)$?
The priors become $\tfrac23$ and $\tfrac13$. Every $p(\mathbf x\mid y_1)$ gets twice the weight, so the boundary moves to where $\frac{p(\mathbf x\mid y_1)}{p(\mathbf x\mid y_2)}=\tfrac12$: away from class 1, into class 2's side. Region $\Omega_1$ grows.

11Handwriting blueprint

Write each step on paper first, then reveal it to check.

1 · Boundary of two 1-D Gaussians with equal variance

  1. Set the scaled densities equal: $P_1\,\mathcal N(x;\mu_1,\sigma^2)=P_2\,\mathcal N(x;\mu_2,\sigma^2)$.
  2. Take logs. The factors $\frac{1}{\sqrt{2\pi}\,\sigma}$ are equal on both sides and cancel: $\ln P_1-\frac{(x-\mu_1)^2}{2\sigma^2}=\ln P_2-\frac{(x-\mu_2)^2}{2\sigma^2}$.
  3. Expand the squares. The $x^2$ terms cancel: that is why equal variances give a single, linear boundary.
  4. Collect the terms: $\frac{\mu_2-\mu_1}{\sigma^2}\,x=\frac{\mu_2^2-\mu_1^2}{2\sigma^2}+\ln\frac{P_1}{P_2}$.
  5. Solve: $x^*=\frac{\mu_1+\mu_2}{2}+\frac{\sigma^2}{\mu_2-\mu_1}\ln\frac{P_1}{P_2}$. Check: equal priors give the midpoint; $P_1>P_2$ pushes $x^*$ towards $\mu_2$ (here $\mu_2>\mu_1$).

2 · Unequal variances: the boundary becomes quadratic

  1. Same start, but now the normalisers differ: $\ln P_1-\ln\sigma_1-\frac{(x-\mu_1)^2}{2\sigma_1^2}=\ln P_2-\ln\sigma_2-\frac{(x-\mu_2)^2}{2\sigma_2^2}$.
  2. The $x^2$ terms no longer cancel: their coefficients are $-\frac{1}{2\sigma_1^2}$ and $-\frac{1}{2\sigma_2^2}$.
  3. Move everything to one side: $a x^2+bx+c=0$ with $a=\frac{1}{2\sigma_2^2}-\frac{1}{2\sigma_1^2}$, $b=\frac{\mu_1}{\sigma_1^2}-\frac{\mu_2}{\sigma_2^2}$ and $c=\frac{\mu_2^2}{2\sigma_2^2}-\frac{\mu_1^2}{2\sigma_1^2}+\ln\frac{P_1\sigma_2}{P_2\sigma_1}$.
  4. This has up to two roots: the wider class wins on both far sides, the narrower one in between. Try it in the explorer (untick "equal variances").
  5. In more dimensions the same algebra gives a quadratic boundary (QDA, Week 1b), and equal covariance matrices give a linear one (LDA).

3 · The two-class minimum-risk rule

  1. Risk of saying $y_1$: $l^1(\mathbf x)=\lambda_{11}\,p(y_1\mid\mathbf x)+\lambda_{21}\,p(y_2\mid\mathbf x)=\lambda_{21}\,p(y_2\mid\mathbf x)$, because $\lambda_{11}=0$.
  2. Risk of saying $y_2$: $l^2(\mathbf x)=\lambda_{12}\,p(y_1\mid\mathbf x)$.
  3. Say $y_1$ when $l^1<l^2$: $\lambda_{21}\,p(y_2\mid\mathbf x)<\lambda_{12}\,p(y_1\mid\mathbf x)$.
  4. Use Bayes' rule on both sides; $p(\mathbf x)$ cancels: $\lambda_{21}\,p(\mathbf x\mid y_2)\,p(y_2)<\lambda_{12}\,p(\mathbf x\mid y_1)\,p(y_1)$.
  5. Likelihood-ratio form: $\frac{p(\mathbf x\mid y_1)}{p(\mathbf x\mid y_2)}>\frac{\lambda_{21}\,p(y_2)}{\lambda_{12}\,p(y_1)}$. Costs and priors play the same role: both only scale the threshold.

4 · Bayes error of the two triangles (Exercise 1.5)

  1. Write the densities: $p(x\mid\omega_1)=1-|x|$ on $[-1,1]$; $p(x\mid\omega_2)=x/4$ on $[0,2]$ and $(4-x)/4$ on $[2,4]$.
  2. They overlap only on $[0,1]$. With equal priors compare $1-x$ with $x/4$: they are equal at $x=0.8$.
  3. On $[0,0.8]$ you say $\omega_1$, so you lose the $\omega_2$ objects there: $\tfrac12\int_0^{0.8}\tfrac x4\,dx=\tfrac12\cdot\tfrac{0.8^2}{8}=0.04$.
  4. On $[0.8,1]$ you say $\omega_2$, so you lose the $\omega_1$ objects there: $\tfrac12\int_{0.8}^{1}(1-x)\,dx=\tfrac12\cdot\tfrac{0.2^2}{2}=0.01$.
  5. Add them: $\varepsilon^*=0.04+0.01=\mathbf{0.05}$. Check: both pieces are triangles, so "½ · base · height" gives the same numbers.

12Exam traps

Watch out
  • "Better posterior estimates (or more data) lower the Bayes error." False. $\varepsilon^*$ is a property of the true distributions.
  • "A flexible enough classifier gets the Bayes error to 0." False whenever the classes overlap. A training error of 0 is overfitting, not beating $\varepsilon^*$.
  • "Equal priors ⇒ boundary at the midpoint." Only for equal variances. With unequal variances the boundary is quadratic and can have two points.
  • Prior direction. A larger $P(\omega_1)$ moves the boundary away from $\mu_1$, into class 2's side: $\Omega_1$ grows.
  • Cost direction. If calling a true $\omega_2$ "$\omega_1$" is expensive ($\lambda_{21}$ large), $\Omega_1$ shrinks. Write $\lambda_{ji}$ = true $j$ → decided $i$ and state the convention.
  • Minimum risk ≠ minimum error. With costs you deliberately make more (cheaper) mistakes.
  • "In 0 dimensions the error is always 0.5." False (24/25 exam). Without features you can only predict the most common class: error $=1-\max_i P(\omega_i)$, which is 0.5 only for two equally likely classes.
  • $p(\mathbf x\mid y)$ can be larger than 1. It is a density over $\mathbf x$. Only priors and posteriors live in $[0,1]$.
  • You don't need $p(\mathbf x)$ to classify, only to normalise. Comparing $p(\mathbf x\mid y_i)\,p(y_i)$ is enough.
  • Uniform densities. Where both are flat the posteriors are constant. Equal heights give a tie (any boundary in the overlap works), and in a gap where $p(\mathbf x)=0$ the boundary can be anywhere without changing the error.
  • Training error vs true error. The error counted on the training set can be below $\varepsilon^*$; the expected error on new data cannot.
  • Adding a feature never increases the Bayes error (you could always ignore it), but with finite data it can increase the error of a real classifier: the curse of dimensionality (Week 1b).

13Self-check

Answer first, then open. past exam marks questions from the 24/25 exam reviews.

1. past exam True or false: when $\mathbf x$ is a feature vector and $\omega$ the class label, Bayes' rule states $p(\omega\mid\mathbf x)=p(\mathbf x\mid\omega)\,p(\omega)/p(\mathbf x)$.
True. Posterior = likelihood × prior / evidence.
2. past exam True or false: the Bayes error is always smaller than or equal to the estimated true error. You may assume there is sufficient data.
True. No classifier has a true error below $\varepsilon^*$, and with sufficient (test) data the estimate is close to the true error. "Sufficient data" is there to rule out a lucky small test set.
3. past exam True or false: in 0 dimensions, the classification error will always be 0.5.
False. With no features the best you can do is always predict the class with the largest prior. The error is $1-\max_i P(\omega_i)$: 0.3 for priors 0.7/0.3, and 0.5 only for two equal priors.
4. past exam True or false: using feature extraction, any multidimensional problem can in principle be reduced to a one-dimensional one without increasing the Bayes error.
True. For two classes, use the posterior itself as the new feature: $z=p(\omega_1\mid\mathbf x)$. The Bayes classifier only ever needs to know whether $z>0.5$, so nothing that matters for the decision is lost. ("In principle": you would need the true posterior to build that feature.)
5. past exam You have an imbalanced data set where misclassifying the minority class costs more than misclassifying the majority class. What is an effective strategy, using Bayes' rule?
Give the minority class a higher weight (a higher cost $\lambda$) during training or when deciding. In Bayes terms you compare cost-weighted posteriors (Part 6), so the threshold for predicting the minority class drops. Plain accuracy would favour the majority class.

6. exam style Four classes in one dimension

Four classes with the class densities below and equal priors. Find (a) the priors, (b) the decision boundaries of the Bayes classifier, (c) the Bayes error. Modelled on 24/25 exam question 19; that question's figure isn't in your folder, so these densities are new.

Show worked solution

(a) Four classes with equal priors: $P(\omega_i)=\tfrac14$.

(b) With equal priors you only compare the heights of the densities, interval by interval:

  • $[1,2]$: $\omega_1$ (0.5) against the rising triangle $\omega_2$ (height $x-1$): equal at $x=1.5$.
  • $[2,2.5]$: only $\omega_2$ (falling from 1 to 0.5).
  • $[2.5,3]$: $\omega_3$ (0.5) beats the falling $\omega_2$ ($3-x\le0.5$): boundary at $x=2.5$.
  • $[4,4.5]$: $\omega_4$ (1) beats $\omega_3$ (0.5): boundary at $x=4$.

Boundaries at $x=1.5,\ 2.5,\ 4$. Regions: $\omega_1$ on $[0,1.5]$, $\omega_2$ on $[1.5,2.5]$, $\omega_3$ on $[2.5,4]$, $\omega_4$ on $[4,5]$.

(c) Add up the pieces you lose (each density × ¼):

7. $\mu_1=0$, $\mu_2=2$, $\sigma^2=1$ for both classes, $P(\omega_1)=0.75$. Where is the boundary?
$x^*=\frac{0+2}{2}+\frac{1}{2}\ln\frac{0.75}{0.25}=1+\tfrac12\ln3\approx\mathbf{1.549}$. It moved from 1 towards $\mu_2$ because $\omega_1$ is more common.
8. The densities of Exercise 1.1(a) ($\mu_1=0,\ \mu_2=1,\ \sigma^2=\tfrac12$, equal priors) with loss matrix $L=\begin{pmatrix}0&1\\4&0\end{pmatrix}$, rows = true class. Where is the boundary?
$\lambda_{12}=1$ and $\lambda_{21}=4$. Say $\omega_1$ if $\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)}>\frac{\lambda_{21}}{\lambda_{12}}=4$. Here $\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)}=e^{\,1-2x}$, so $1-2x>\ln4$, i.e. $x<\frac{1-\ln4}{2}\approx\mathbf{-0.193}$. Calling a true $\omega_2$ "$\omega_1$" is expensive, so $\Omega_1$ shrinks a lot.
9. $\omega_1$ is uniform on $[0,2]$, $\omega_2$ uniform on $[1,5]$, equal priors. What is $P(\omega_1\mid x=1.5)$, and where is the boundary?
The heights are $\tfrac12$ and $\tfrac14$. $P(\omega_1\mid1.5)=\frac{\frac12\cdot\frac12}{\frac12\cdot\frac12+\frac14\cdot\frac12}=\frac23$. The posterior is the same everywhere on the overlap $[1,2]$ and $\omega_1$ wins it, so the boundary is at $x=2$.
10. Which of these can lower the Bayes error? (a) more training data (b) a more flexible classifier (c) adding an informative feature (d) better density estimates
(c). The Bayes error belongs to the feature representation: a new informative feature can pull the classes apart. (a), (b) and (d) only bring a classifier closer to $\varepsilon^*$. (In practice (c) can still hurt with little data: the curse of dimensionality.)
11. Reject option with $\theta=0.7$. Two objects have posteriors $(0.65,\,0.35)$ and $(0.72,\,0.28)$. What happens to each?
First: $\max=0.65<0.7$, so it is rejected. Second: $\max=0.72\ge0.7$, so it is assigned to $\omega_1$.
12. A classifier has 0% error on its training set, and the Bayes error of the problem is 10%. Is that a contradiction?
No. The training (apparent) error is measured on the objects the classifier was fitted to: it memorised them. On new objects its error will be at least 10%. This is overfitting (slide 17).

Exercise 1.1 · Decision boundaries

(a) $\omega_1\sim\mathcal N(0,\tfrac12)$, $\omega_2\sim\mathcal N(1,\tfrac12)$, equal priors: derive the boundary. (b) $\omega_1$ uniform on $[0,1]$, $\omega_2$ uniform on $[2,3]$. (c) $\omega_2$ uniform on $[0.5,1.5]$ instead. (d) $\omega_2$ uniform on $[0.5,2.5]$ instead. Equal priors throughout.

You need: the boundary is where $p(x\mid\omega_1)P(\omega_1)=p(x\mid\omega_2)P(\omega_2)$ (§4). A uniform density on $[a,b]$ has height $\frac{1}{b-a}$.

Hint

For (a), use blueprint 1. For (b)–(d), draw both rectangles at their true heights. Where only one is non-zero, that class wins; where both are, the taller one wins.

Show worked solution

(a) Equal variances and equal priors: $x^*=\frac{0+1}{2}=\mathbf{0.5}$ (the log-prior term is 0). The Bayes error is about $0.240$ (Part 5).

(b) No overlap. Every point in $[0,1]$ is $\omega_1$, every point in $[2,3]$ is $\omega_2$. In the gap $[1,2]$ no objects ever occur ($p(x)=0$), so any boundary in $[1,2]$ is optimal, with $\varepsilon^*=0$. The midpoint 1.5 is the natural choice.

(c) Both heights are 1 on the overlap $[0.5,1]$, so there $P(\omega_1\mid x)=P(\omega_2\mid x)=\tfrac12$: a tie. Any boundary in $[0.5,1]$ gives the same error, $\varepsilon^*=\tfrac12\cdot1\cdot0.5=\mathbf{0.25}$.

(d) Now $\omega_2$ has height $\tfrac12$, so on $[0.5,1]$ $\omega_1$ (height 1) wins: boundary at $x=1$, and $\varepsilon^*=\tfrac12\cdot\tfrac12\cdot0.5=\mathbf{0.125}$ (the $\omega_2$ objects in $[0.5,1]$).

Exercise 1.2 · Boundaries with a loss matrix

(a) The Gaussians of 1.1(a), equal priors, loss matrix $L=\begin{pmatrix}0&0.5\\1.0&0\end{pmatrix}$. (b) $\omega_1$ uniform on $[0,1]$, $\omega_2$ uniform on $[0.5,2.5]$, the same $L$.

You need: the two-class minimum-risk rule (§6, blueprint 3). Convention: rows = true class, as on the slides, so $\lambda_{12}=0.5$ (true $\omega_1$ called $\omega_2$) and $\lambda_{21}=1.0$ (true $\omega_2$ called $\omega_1$).

Hint

Say $\omega_1$ when $\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)}>\frac{\lambda_{21}P(\omega_2)}{\lambda_{12}P(\omega_1)}$. Work out that threshold number first, then the likelihood ratio of the two Gaussians.

Show worked solution

(a) Threshold: $\frac{\lambda_{21}}{\lambda_{12}}=\frac{1.0}{0.5}=2$ (the priors are equal). Likelihood ratio: $\frac{p(x\mid\omega_1)}{p(x\mid\omega_2)}=\exp\!\big(-x^2+(x-1)^2\big)=e^{\,1-2x}.$

$$e^{\,1-2x}>2\iff 1-2x>\ln2\iff x<\frac{1-\ln2}{2}\approx\mathbf{0.153}$$

Check with risk and error: at 0.5 the risk is 0.180 and the error 0.240; at 0.153 the risk is 0.161 (lower) but the error is 0.265 (higher).

(b) On the overlap $[0.5,1]$: the risk of saying $\omega_1$ is $\lambda_{21}\,p(x\mid\omega_2)P(\omega_2)=1.0\cdot0.5\cdot0.5=0.25$; the risk of saying $\omega_2$ is $\lambda_{12}\,p(x\mid\omega_1)P(\omega_1)=0.5\cdot1\cdot0.5=0.25$. Equal! The costs exactly cancel the height difference, so the whole overlap is a tie: any boundary in $[0.5,1]$ gives the minimum risk. (Without costs it was at $x=1$; see 1.1d.)

If you read L the other way round

With rows = decision ($\lambda_{12}=1.0$, $\lambda_{21}=0.5$) you get (a) $x=\frac{1+\ln2}{2}\approx0.847$ and (b) a boundary at $x=1$. Both are right for that convention, which is exactly why you state it.
