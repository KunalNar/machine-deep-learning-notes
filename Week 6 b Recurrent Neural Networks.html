Recurrent Neural Networks: RNN, GRU, LSTM

Text, speech and video are sequences: their length varies and the order matters. A recurrent neural network reads a sequence one step at a time with the same weights, and carries a hidden state that summarises everything it has seen. Training it means backpropagating through every time step, which multiplies one derivative per step, so gradients vanish or explode over long sequences. GRUs and LSTMs fix this with gates: small learned switches that let information, and its gradient, pass through unchanged.

Answer out loud before you read on. Each answer points to the part that explains it.

1. True or false: for longer input sequences, a recurrent neural network needs more parameters.
False (a 24/25 exam question). The same weights are used at every time step, so the number of parameters doesn't depend on the sequence length. → Part 4
2. In "hello", the first "l" must be followed by "l" and the second "l" by "o". Why can't a network that looks at one character at a time get both right?
Both inputs are the same "l", so a network without memory gives the same output twice. It needs to know what came before: that is the job of the hidden state $\mathbf H_{t-1}$. → Part 3
3. In a GRU, $\mathbf H_t=\mathbf Z_t\odot\mathbf H_{t-1}+(1-\mathbf Z_t)\odot\tilde{\mathbf H}_t$. What happens when $\mathbf Z_t$ is a vector of ones?
$\mathbf H_t=\mathbf H_{t-1}$: the input has no effect and the old state is copied unchanged (no update). That copy path is how gated networks keep information, and gradients, alive over long sequences. → Part 6

One sentence to remember

An RNN applies the same cell at every time step, $\mathbf H_t=\phi(\mathbf X_t\mathbf W_{xh}+\mathbf H_{t-1}\mathbf W_{hh}+\mathbf b_h)$, so its parameters don't grow with the sequence. Training multiplies one derivative per step, so long-range gradients vanish or explode. GRUs and LSTMs add gates, vectors in $(0,1)$, that can copy the state almost unchanged from step to step.

2Sequence data slides 3–4 DL book 10 · D2L 9.1

Why not a normal MLP? (slide 4)

Take a translation system with one word per input: The student, after reading the book, was well prepared.

  • Sequences have variable length. An MLP has a fixed number of inputs.
  • "Just pad with zeros"? Then the MLP learns exact word positions: "student" in position 2 and "student" in position 5 go through different weights.
  • Why is that a problem? It would have to see every word in every position during training, which is impossible.

What we need is the same idea as convolution in images, weight sharing, now over time, plus a memory: "was" has to agree with "student", six words earlier.

4The RNN equations slides 11–12, 23 D2L 9.4 · Bishop & Bishop 12.2.5

Formula (slide 11)

For a sequence $\mathbf X_t$, $t=1,2,\dots,T$:

$$\mathbf H_t=\phi\big(\mathbf X_t\mathbf W_{xh}+\mathbf H_{t-1}\mathbf W_{hh}+\mathbf b_h\big),\qquad\mathbf O_t=\mathbf H_t\mathbf W_{hq}+\mathbf b_q$$
  • $\mathbf H_t$: activation at the current time step; $\mathbf H_{t-1}$: activation at the previous step ($\mathbf H_0=\mathbf 0$).
  • $\phi$: the non-linearity, often tanh, with range $(-1,1)$.
  • $\mathbf X_t$: the input at time $t$; $\mathbf W_{xh}$: learned weights for that input.
  • $\mathbf W_{hh}$: learned weights that decide how to use the previous information.
  • $\mathbf W_{hq}$: learned output weights; $\mathbf b_h,\mathbf b_q$: learned biases.

The number of parameters doesn't grow with the sequence length (slide 12)

$d\,h+h^2+h$ for the recurrent layer plus $h\,q+q$ for the output: no $T$ anywhere. For "hello": $12+9+3+12+4=40$, whether the word has 5 letters or 5,000. "For longer sequences the RNN needs more parameters" is false (24/25 exam).

Tiny numbers: memory fades

A 1-D RNN: $h_t=\tanh(1\cdot x_t+0.5\,h_{t-1})$, one input $x_1=1$, then zeros:

$h_1=\tanh(1)=0.76$, $\;h_2=\tanh(0.38)=0.36$, $\;h_3=\tanh(0.18)=0.18$, $\;h_4=0.09$.

Every step keeps about half: after a dozen steps the network has forgotten the input. The widget below lets you change both weights.

Code: vanilla RNN forward with basic tensor operations
# x: (T, N, d)   W_xh: (d, h)   W_hh: (h, h)   b_h: (h,)
H = torch.zeros(N, h)                              # H_0
outs = []
for t in range(T):
    H = torch.tanh(x[t] @ W_xh + H @ W_hh + b_h)   # (N, h): same weights every step
    outs.append(H)
Hs = torch.stack(outs)                             # (T, N, h)

5Gradients through time slide 14 D2L 9.7 · Bishop & Bishop 12.2.6

Formula (slide 14)

RNNs apply the same function, with shared weights, at each time step: $z=f_3\big(x_3,f_2(x_2,f_1(x_1,w),w),w\big)$. The derivative contains

$$\frac{dz}{dw}\ni\frac{df_3}{df_2}\,\frac{df_2}{df_1}\,\frac{df_1}{dw},\qquad\text{and for length }T:\qquad\frac{df_1}{dw}\prod_{t=2}^{T}\frac{df_t}{df_{t-1}}.$$
  • If $\big|\frac{df_t}{df_{t-1}}\big|<1$, then for $T=1000$: $\frac{dz}{dw}\approx0$ (it vanishes).
  • If $\big|\frac{df_t}{df_{t-1}}\big|>1$, then for $T=1000$: $\frac{dz}{dw}\approx\infty$ (it explodes).

In a vanilla RNN every factor is $\frac{\partial\mathbf H_t}{\partial\mathbf H_{t-1}}=\operatorname{diag}\big(\phi'(\cdot)\big)\,\mathbf W_{hh}^\top$: the same $\mathbf W_{hh}$ again and again, times a tanh slope that is at most 1.

Tiny numbers

$0.9^{10}=0.35$, $\;0.9^{100}=2.7\times10^{-5}$, $\;0.9^{1000}=1.7\times10^{-46}$.

$1.1^{100}=1.4\times10^{4}$, $\;1.1^{1000}=2.5\times10^{41}$.

A factor only 10% away from 1 is enough to kill or blow up the signal over a long sequence.

Why this matters (slide 14)

The student[s], after reading the paper… book… blog…, was [were] well prepared. To learn that "was" must agree with "student", the gradient from "was" has to travel back through every word in between. RNNs have difficulty backpropagating such long-range relations.

Not on the slides, but standard: exploding gradients are tamed by gradient clipping (rescale the gradient when its norm is too large). Vanishing gradients need a different cell: the gates of the next two parts.

6GRU: gated recurrent unit slides 15–18 D2L 10.2

Intuition (slide 15)

Improve the hidden state for long-range relations with two abilities:

  • Reset for a new logical chunk of the input (a new chapter in a book): forget the old state.
  • Don't update for uninformative input (html codes in a web page): keep the old state as it is.

Both are done with gates: vectors with entries in $(0,1)$, inspired by logic gates. Multiplying a vector element-wise ($\odot$) by a gate keeps the entries where the gate is near 1 and removes them where it is near 0, one dimension at a time (slide 16).

Formula (slide 16)

The gates are learned from what is available, the current input and the previous state, with a sigmoid to force them into $(0,1)$:

$$\mathbf R_t=\sigma(\mathbf X_t\mathbf W_{xr}+\mathbf H_{t-1}\mathbf W_{hr}+\mathbf b_r),\qquad\mathbf Z_t=\sigma(\mathbf X_t\mathbf W_{xz}+\mathbf H_{t-1}\mathbf W_{hz}+\mathbf b_z)$$

The reset gate shapes the candidate state, and the update gate mixes old and candidate:

$$\tilde{\mathbf H}_t=\tanh\big(\mathbf X_t\mathbf W_{xh}+(\mathbf R_t\odot\mathbf H_{t-1})\mathbf W_{hh}+\mathbf b_h\big),\qquad\mathbf H_t=\mathbf Z_t\odot\mathbf H_{t-1}+(1-\mathbf Z_t)\odot\tilde{\mathbf H}_t$$

Each gate "looks familiar": it is a standard RNN layer with a sigmoid instead of tanh.

Tiny numbers: one GRU step (1-D)

Old state $H_{t-1}=0.8$, input $X_t=0.5$, all weights 1, biases 0, and suppose the gates come out as $R_t=0.2$ and $Z_t=0.9$.

Candidate: $\tilde H_t=\tanh(0.5+0.2\cdot0.8)=\tanh(0.66)=0.578$.

New state: $H_t=0.9\cdot0.8+0.1\cdot0.578=0.72+0.058=0.778$: almost the old state. With $Z_t=0$ it would be $0.578$.

Why gating allows long-term relations (slide 18)

Relevant long-term information can pass through unchanged. Where $\mathbf Z_t\approx1$, $\mathbf H_t\approx\mathbf H_{t-1}$, so the factor $\frac{\partial\mathbf H_t}{\partial\mathbf H_{t-1}}$ in the backprop product is about 1 along that path: neither vanishing nor exploding.

Convention: the slides (and D2L, and PyTorch) put $\mathbf Z_t$ on the old state, so $\mathbf Z_t=\mathbf 1$ means "no update". Some blogs swap $\mathbf Z_t$ and $1-\mathbf Z_t$. In the exam, use the slides' version.

7LSTM: long short-term memory slides 19–20 D2L 10.1 · colah's blog

Intuition (slide 19)

The LSTM keeps a second state, the memory cell $\mathbf C_t$: a conveyor belt that information rides along. The LSTM only adds and removes information on it linearly, through gates. The gates and the candidate cell depend on the input and the previous hidden state; the new cell depends on the old cell and the candidate; the hidden state is read from the cell.

Formula (slide 19)

Three gates, computed like the GRU's, and a candidate cell:

$$\mathbf I_t=\sigma(\mathbf X_t\mathbf W_{xi}+\mathbf H_{t-1}\mathbf W_{hi}+\mathbf b_i),\quad\mathbf F_t=\sigma(\mathbf X_t\mathbf W_{xf}+\mathbf H_{t-1}\mathbf W_{hf}+\mathbf b_f),\quad\mathbf O_t=\sigma(\mathbf X_t\mathbf W_{xo}+\mathbf H_{t-1}\mathbf W_{ho}+\mathbf b_o)$$ $$\tilde{\mathbf C}_t=\tanh(\mathbf X_t\mathbf W_{xc}+\mathbf H_{t-1}\mathbf W_{hc}+\mathbf b_c)$$

Where the GRU has one update gate ($\mathbf H_t=\mathbf Z_t\odot\mathbf H_{t-1}+(1-\mathbf Z_t)\odot\tilde{\mathbf H}_t$), the LSTM has two, forget and input:

$$\mathbf C_t=\mathbf F_t\odot\mathbf C_{t-1}+\mathbf I_t\odot\tilde{\mathbf C}_t,\qquad\mathbf H_t=\mathbf O_t\odot\tanh(\mathbf C_t)$$
Tiny numbers: one LSTM step (1-D)

$C_{t-1}=2$, forget gate $F_t=0.9$, input gate $I_t=0.2$, candidate $\tilde C_t=-1$, output gate $O_t=0.5$:

$C_t=0.9\cdot2+0.2\cdot(-1)=1.8-0.2=1.6$, $\qquad H_t=0.5\cdot\tanh(1.6)=0.5\cdot0.92=0.46$.

The forget gate kept 90% of the old memory, the input gate wrote a little new memory, and the output gate showed half of it.

The 3-second rule
  • σ → gate → "how much" (0 to 1). Multiplying by a gate with ⊙ lets an entry through (near 1) or blocks it (near 0). A gate is just a tensor you compute every step; it isn't a switch someone sets.
  • tanh → content → "what" (−1 to 1). Candidates are drafts; they never survive the step.
  • Only states survive: RNN and GRU carry $\mathbf H$; the LSTM carries $\mathbf H$ and $\mathbf C$. The output $y$ always receives $\mathbf H$.

Your answers, corrected (16 Oct)
  • "The candidate is forget + input, the updated memory that goes to the next step." That's the memory cell $\mathbf C_t$. The candidate $\tilde{\mathbf C}_t$ is the temporary sticky note, and $\mathbf H_t=\mathbf O_t\odot\tanh(\mathbf C_t)$ uses the cell, not the candidate.
  • "No gates are defined in the forward pass, so how do we know if one is open?" A gate is a tensor you compute with σ at every step, for every sample and every unit. "Open" means its value is close to 1; the weights learn when.
  • "Exploding gradients stop the vanilla RNN from learning MNIST-1D." Vanishing: tanh's slope is ≤ 1, and backprop multiplies 40 of those factors (one per time step), so the signal shrinks to almost 0.
  • "The GRU can choose how much of the past to pass on; the vanilla RNN can't." Right for the forward pass. The vanilla RNN also passes the past on, but it has to rewrite it through $\mathbf W_{hh}$ and tanh every step. For learning, the key point is that $\mathbf Z_t\approx1$ makes $\mathbf H_t\approx\mathbf H_{t-1}$, a near-identity path with a gradient factor of about 1.
  • "Weight times data, like in the formula." With the batch in the rows, the data goes left: $(N,d)\,@\,(d,h)\to(N,h)$. Work out the order from the shapes, not from how the formula is written.

8Recap

What to know for the exam (slide 22)
  • RNNs: $\mathbf H_t=\phi(\mathbf X_t\mathbf W_{xh}+\mathbf H_{t-1}\mathbf W_{hh}+\mathbf b_h)$, $\mathbf O_t=\mathbf H_t\mathbf W_{hq}+\mathbf b_q$; the same weights at every step, so the parameters don't grow with $T$.
  • Vanishing/exploding gradients: backprop through time multiplies one factor $\frac{df_t}{df_{t-1}}$ per step; below 1 it vanishes, above 1 it explodes.
  • GRU and LSTM: sigmoid gates in $(0,1)$ and element-wise products let information and gradients pass through unchanged. GRU: reset and update gate. LSTM: input, forget and output gate, plus a memory cell.

9Handwriting blueprint

Write each step on paper first, then reveal it.

1 · Two RNN steps by hand

  1. $h_t=\tanh(w_{xh}x_t+w_{hh}h_{t-1})$ with $w_{xh}=1$, $w_{hh}=0.5$, $h_0=0$, inputs $x_1=1$, $x_2=0$.
  2. $h_1=\tanh(1\cdot1+0.5\cdot0)=\tanh(1)=0.76$.
  3. $h_2=\tanh(1\cdot0+0.5\cdot0.76)=\tanh(0.38)=0.36$.
  4. The same two weights were used in both steps: the memory of $x_1$ is scaled by about $w_{hh}$ per step.

2 · Counting parameters ($d$ inputs, $h$ hidden, $q$ outputs)

  1. Recurrent layer: $\mathbf W_{xh}$ has $d\,h$, $\mathbf W_{hh}$ has $h^2$, $\mathbf b_h$ has $h$: in total $(d+h)h+h$.
  2. Output layer: $h\,q+q$. Nothing depends on $T$.
  3. Hello ($d=4$, $h=3$, $q=4$): $12+9+3=24$, plus $12+4=16$, gives 40.
  4. GRU: three such layers (reset, update, candidate) = 72. LSTM: four (input, forget, output, candidate) = 96.

3 · Why the gradient vanishes (1-D)

  1. $h_t=\tanh(a_t)$ with $a_t=w_{xh}x_t+w_{hh}h_{t-1}$.
  2. Chain rule: $\frac{\partial h_t}{\partial h_{t-1}}=\tanh'(a_t)\,w_{hh}=(1-h_t^2)\,w_{hh}$.
  3. Over many steps: $\frac{\partial h_T}{\partial h_1}=\prod_{t=2}^{T}(1-h_t^2)\,w_{hh}$.
  4. $0<1-h_t^2\le1$, so if $|w_{hh}|<1$ every factor is below 1 and the product goes to 0 exponentially fast. If $|w_{hh}|>1$ and the state stays small, the product explodes.

4 · One GRU step by hand

  1. Given $H_{t-1}=0.8$, $X_t=0.5$, weights 1, biases 0, gates $R_t=0.2$, $Z_t=0.9$.
  2. Reset first: $R_t\odot H_{t-1}=0.16$.
  3. Candidate: $\tilde H_t=\tanh(0.5+0.16)=\tanh(0.66)=0.578$.
  4. Mix: $H_t=Z_t\,H_{t-1}+(1-Z_t)\,\tilde H_t=0.72+0.058=0.778$.

5 · One LSTM step by hand

  1. Given $C_{t-1}=2$, $F_t=0.9$, $I_t=0.2$, $\tilde C_t=-1$, $O_t=0.5$.
  2. Forget: $F_t\,C_{t-1}=1.8$. Write: $I_t\,\tilde C_t=-0.2$.
  3. New cell: $C_t=1.8-0.2=1.6$.
  4. Read out: $H_t=O_t\tanh(C_t)=0.5\cdot0.92=0.46$.

10Exam traps

Watch out
  • Longer sequences don't need more parameters (24/25 #36): the weights are shared over time.
  • All parameters are shared across time steps, in RNNs, GRUs and LSTMs alike (24/25 #51).
  • Vanish vs explode: per-step factor below 1 → vanishes, above 1 → explodes; it's a product of $T-1$ factors, so even 0.9 or 1.1 is fatal for long sequences.
  • Gates use a sigmoid (range $(0,1)$); candidates use tanh (range $(-1,1)$).
  • $\odot$ is element-wise, not a matrix product. A gate switches every dimension of the state separately.
  • GRU convention: on the slides $\mathbf Z_t=\mathbf 1$ keeps the old state (no update). Some sources swap $\mathbf Z_t$ and $1-\mathbf Z_t$.
  • GRU vs LSTM: 2 gates and no separate cell vs 3 gates plus a memory cell; $\mathbf H_t=\mathbf O_t\odot\tanh(\mathbf C_t)$. Their common idea is gating (2025 MC 12).
  • Concatenation $[\mathbf X_t\,|\,\mathbf H_{t-1}]\begin{bmatrix}\mathbf W_{xh}\\\mathbf W_{hh}\end{bmatrix}=\mathbf X_t\mathbf W_{xh}+\mathbf H_{t-1}\mathbf W_{hh}$: the same model.
  • Biases: the slides use one bias per layer; PyTorch and the exam's RNN code use two ($b_{xh}$ and $b_{hh}$). They add up to one, but the parameter count differs by $h$ per layer.
  • Activation in the exam code: the 24/25 vanilla RNN answer uses a sigmoid; the slides say "often tanh". Use what the question gives.

11Self-check

Answer first, then open. past exam marks questions from the exam reviews.

1. past exam True or false: for longer input sequences, the number of parameters of recurrent neural networks should be increased accordingly. (24/25 #36)
False. The same $\mathbf W_{xh},\mathbf W_{hh},\mathbf W_{hq}$ are used at every time step.
2. past exam Which statement about RNNs, GRUs and LSTMs is most correct? (24/25 #51)
"In both standard RNNs and GRUs, all the parameters are shared across time steps." (LSTMs share theirs too.)
3. past exam Both GRUs and LSTMs address vanishing gradients over time and keep relations between elements that are far apart. What is similar in their approach? (2025 MC 12)
They rely on gating mechanisms that decide when to update, retain or forget information.
4. Why not feed a whole sentence, padded with zeros to a fixed length, into an MLP?
The MLP would learn exact word positions: the same word at another position goes through other weights, so it would need to see every word in every position during training (slide 4).
5. What range do the values of a gate have, and which function guarantees it?
$(0,1)$, guaranteed by the sigmoid $\sigma$. That is why a gate can act as a soft switch: multiply by about 0 to block, about 1 to pass.
6. In the slides' GRU, what does $\mathbf R_t=\mathbf 0$ do? And $\mathbf Z_t=\mathbf 0$?
$\mathbf R_t=\mathbf 0$: the candidate ignores the previous state, $\tilde{\mathbf H}_t=\tanh(\mathbf X_t\mathbf W_{xh}+\mathbf b_h)$ (a reset). $\mathbf Z_t=\mathbf 0$: the new state is the candidate, $\mathbf H_t=\tilde{\mathbf H}_t$ (a full update).
7. Which LSTM gate decides how much of $\mathbf C_{t-1}$ to keep, and which decides how much of the cell to show in $\mathbf H_t$?
The forget gate $\mathbf F_t$ multiplies $\mathbf C_{t-1}$; the output gate $\mathbf O_t$ multiplies $\tanh(\mathbf C_t)$.
8. Why does gating help against vanishing gradients? (slide 18)
Where a gate keeps the state ($\mathbf Z_t\approx1$, or $\mathbf F_t\approx1$), the state is copied almost unchanged, so the derivative from one step to the next is about 1: the long product neither vanishes nor explodes, and relevant long-term information passes through unchanged.
9. An RNN has $d=10$ inputs, $h=20$ hidden units and $q=5$ outputs. How many parameters (one bias per layer)?
$10\cdot20+20\cdot20+20=620$ for the recurrent layer, $20\cdot5+5=105$ for the output: 725, for any sequence length.
10. Each backprop step through time multiplies the gradient by about 0.95. How much is left after 100 steps?
$0.95^{100}\approx0.006$: less than 1%. After 1000 steps, about $5\times10^{-23}$.

past exam E1 · Vanilla RNN forward (24/25 #50)

The input x has shape (T, N, D). The layer has weight_xh (D, H), weight_hh (H, H) and biases bias_xh, bias_hh (H,). Starting from ht_1 = h0, loop over time, compute every hidden state and collect them. Basic tensor operations only (no torch.nn).

Hint

Inside the loop you need two matrix products: x[t] (N, D) with weight_xh, and ht_1 (N, H) with weight_hh, each plus its bias. Then the activation. What must ht_1 become before the next step?

Show worked solution
y = []
ht_1 = h0                                                   # (N, H)
for t in range(T):
    xh = torch.addmm(self.bias_xh, x[t], self.weight_xh)    # bias + x_t @ W_xh: (N, H)
    hh = torch.addmm(self.bias_hh, ht_1, self.weight_hh)    # bias + h_{t-1} @ W_hh: (N, H)
    ht = torch.sigmoid(xh + hh)                             # the review uses sigmoid; tanh is also common
    y.append(ht)
    ht_1 = ht                                               # carry the state to the next step
y = torch.stack(y)                                          # (T, N, H)

torch.addmm(b, A, B) computes b + A @ B; writing x[t] @ self.weight_xh + self.bias_xh is the same. The two biases add up to the slides' single $\mathbf b_h$. The weights don't change inside the loop: that is the parameter sharing of slide 12.

E2 · A GRU cell forward

Write one GRU step: given x_t (N, D) and h_prev (N, H), and weights W_xr, W_xz, W_xh (D, H), W_hr, W_hz, W_hh (H, H) and biases b_r, b_z, b_h (H,), return h_t. Use the slides' equations and basic tensor operations.

Hint

Three lines look like an RNN layer (two with torch.sigmoid, one with torch.tanh), and in one of them the previous state is multiplied element-wise by the reset gate first. The last line mixes old and candidate with the update gate; * is the element-wise product.

Show worked solution
r = torch.sigmoid(x_t @ W_xr + h_prev @ W_hr + b_r)              # reset gate (N, H)
z = torch.sigmoid(x_t @ W_xz + h_prev @ W_hz + b_z)              # update gate (N, H)
h_cand = torch.tanh(x_t @ W_xh + (r * h_prev) @ W_hh + b_h)      # candidate (N, H)
h_t = z * h_prev + (1 - z) * h_cand                              # slides' convention

Check with the tiny numbers of Part 6: with all weights 1, biases 0, $R=0.2$, $Z=0.9$, $H_{t-1}=0.8$ and $X_t=0.5$ you get $0.778$. For a whole sequence, put these four lines inside the loop of E1.

E3 · Counting parameters

Inputs of size $d=4$, hidden size $h=3$, outputs $q=4$ (the hello network). How many parameters do the recurrent part of an RNN, a GRU and an LSTM have (one bias per layer)? How many does the full RNN including the output layer have? What does PyTorch report for nn.RNN(4, 3)?

Hint

One "RNN-like layer" is $\mathbf W_x$ $(d\times h)$ + $\mathbf W_h$ $(h\times h)$ + bias $(h)$. Count how many such layers each cell has.

Show worked solution
  • One layer: $4\cdot3+3\cdot3+3=24$.
  • RNN: 1 layer = 24; with the output layer $3\cdot4+4=16$: 40.
  • GRU: reset, update and candidate = $3\cdot24=$ 72. LSTM: input, forget, output and candidate = $4\cdot24=$ 96.
  • PyTorch has two bias vectors per layer: nn.RNN(4, 3) has $24+3=27$ (and nn.GRU 81, nn.LSTM 108).

None of these depends on the sequence length.

E4 · "hello" by hand

At step 2 the input is "e", the target is "l", and the output scores for (h, e, l, o) are $(0.5,\,0.3,\,-1.0,\,1.2)$. Compute the probability of the target and the cross-entropy loss. Which letter does the network predict?

Hint

Softmax: $e^{\text{score}}$ divided by the sum of all four. The loss is $-\ln p(\text{target})$.

Show worked solution

$e^{0.5}=1.65$, $e^{0.3}=1.35$, $e^{-1.0}=0.37$, $e^{1.2}=3.32$; the sum is $6.69$.

$p(\text l)=0.37/6.69=0.055$, so the loss is $-\ln0.055=2.90$. The largest probability is $p(\text o)=3.32/6.69=0.50$: the network predicts "o", which is wrong. Training pushes the score of "l" up and the others down.

E5 · Will the gradient survive?

A 1-D tanh RNN has $w_{hh}=0.5$. Give an upper bound for $\big|\frac{\partial h_{20}}{\partial h_1}\big|$. Then: with $w_{hh}=1.5$ and a state that stays close to 0, roughly how large is the same derivative?

Hint

Blueprint 3: every factor is $(1-h_t^2)\,w_{hh}$, and $0<1-h_t^2\le1$. How many factors are there between step 1 and step 20?

Show worked solution

19 factors, each at most $0.5$ in size: $\big|\frac{\partial h_{20}}{\partial h_1}\big|\le0.5^{19}\approx1.9\times10^{-6}$. The gradient vanishes.

With $w_{hh}=1.5$ and $h_t\approx0$ the tanh slope is about 1, so the product is about $1.5^{19}\approx2.2\times10^{3}$: it explodes, until the state grows, tanh saturates and the slope drops (the RNN widget in Part 4 shows exactly that).
