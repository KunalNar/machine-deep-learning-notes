Broadcasting

Shapes are compared from the right; a missing or size-1 dimension is stretched. (N, D) + (D,) adds the bias to every row; (C_out, C_in, k, k) * (C_in, k, k) multiplies every filter with the same window; v.view(-1, 1, 1, 1) turns a (C_out,) vector into something that broadcasts against (C_out, C_in, k, k).

3The gradient shape rule

Golden rule

$\partial L/\partial T$ always has exactly the shape of $T$. If you don't remember where a transpose goes, write the shapes down: only one product gives the right shape. Derivations in Week 3b §8.

4Layers and losses from scratch

Linear, ReLU, Sigmoid (Assignments 2–3)
class Linear:
    def __init__(self, d_in, d_out):
        self.weight = torch.empty(d_in, d_out)      # a SHAPE, not a number
        self.bias = torch.empty(d_out)
    def forward(self, x):
        self.cache = x                              # needed for weight_grad
        return x @ self.weight + self.bias          # (N, d_out)
    def backward(self, dup):                        # dup: (N, d_out)
        self.weight_grad = self.cache.T @ dup       # (d_in, d_out)
        self.bias_grad = dup.sum(dim=0)             # (d_out,)
        return dup @ self.weight.T                  # (N, d_in)

class ReLU:
    def forward(self, x):
        self.cache = x
        return torch.clamp(x, min=0)
    def backward(self, dup):
        return dup * (self.cache > 0).float()

class Sigmoid:
    def forward(self, x):
        self.cache = 1 / (1 + torch.exp(-x))        # cache the OUTPUT
        return self.cache
    def backward(self, dup):
        y = self.cache
        return dup * y * (1 - y)
Losses and their gradients
# MSE over all entries: grad = 2 (P - T) / number of entries
def mse(pred, target):
    diff = pred - target
    return (diff ** 2).mean(), 2 * diff / pred.numel()

# numerically stable softmax (subtracting the row max changes nothing)
def softmax(z):
    e = torch.exp(z - z.max(dim=1, keepdim=True).values)
    return e / e.sum(dim=1, keepdim=True)

# softmax + cross-entropy, mean over the batch: grad wrt logits = (Y - T) / N
def cross_entropy(z, t_onehot):
    y = softmax(z)
    loss = -(t_onehot * torch.log(y)).sum(dim=1).mean()
    return loss, (y - t_onehot) / z.shape[0]
Network: backward in reverse, then update
def backward(self, dup):
    for layer in reversed(self.layers):
        dup = layer.backward(dup)
    return dup

def optimizer_step(self, lr):
    for layer in self.layers:
        if hasattr(layer, 'weight'):                # only layers with parameters
            layer.weight -= lr * layer.weight_grad
            layer.bias -= lr * layer.bias_grad

# training loop
for step in range(steps):
    pred = net.forward(x)
    loss, grad = mse(pred, y)
    net.backward(grad)
    net.optimizer_step(lr)

5Optimisers and batch norm

Slide versions of the update rules (Week 4a §5); g is the gradient, all operations element-wise.

EWMA, momentum, RMSprop, Adam
s = rho * s + (1 - rho) * y;  s_hat = s / (1 - rho ** t)            # EWMA, t starts at 1

v = rho * v + (1 - rho) * g;  w -= lr * v                           # momentum (rho = 0.9)

r = rho * r + (1 - rho) * g ** 2;  w -= lr * g / torch.sqrt(r + delta)  # RMSprop

v = rho1 * v + (1 - rho1) * g                                        # Adam (0.9, 0.999)
r = rho2 * r + (1 - rho2) * g ** 2                                   # use rho1/rho2 here,
v_hat = v / (1 - rho1 ** t);  r_hat = r / (1 - rho2 ** t)            # not a leftover global rho!
w -= lr * v_hat / torch.sqrt(r_hat + delta)
Batch norm forward with running averages
def batchnorm(z, gamma, beta, run_mu, run_var, train, rho=0.9, delta=1e-5):
    if train:                                       # statistics per unit, over the batch
        mu, var = z.mean(dim=0), z.var(dim=0, unbiased=False)
        run_mu = rho * run_mu + (1 - rho) * mu
        run_var = rho * run_var + (1 - rho) * var
    else:                                           # test time: running averages
        mu, var = run_mu, run_var
    return gamma * (z - mu) / torch.sqrt(var + delta) + beta, run_mu, run_var

6Convolution and pooling

From your old cheatsheet (CNN assignment). The lecture itself is explained in Week 6a.

TermWhat it isShape
input feature mapdata into the layer(N, C_in, H, W)
filterlearned weights that slide over the input; spans all input channels(C_in, k, k)
weight tensorall filters stacked (PyTorch order)(C_out, C_in, k, k)
biasone per output channel(C_out,)
outputone map per filter(N, C_out, H', W')
Formula
$$H'=1+\Big\lfloor\frac{H+2p-k}{s}\Big\rfloor\quad(\text{same for }W),\qquad\#\text{params}=C_{\text{out}}C_{\text{in}}k^2+C_{\text{out}}.$$

Example: $10\times10$ input, $k=3$, $s=2$, $p=1$: $1+\lfloor9/2\rfloor=5$. A $3\to4$ channel conv with $k=3$ has $4\cdot3\cdot9+4=112$ parameters. Weights are shared over positions and samples, not over channels.

Conv2d forward, max and average pooling (loops, basic ops)
x_pad = torch.nn.functional.pad(x, [p] * 4)            # the assignments allow pad
N, _, H, W = x.shape
Hp, Wp = 1 + (H + 2*p - k) // s, 1 + (W + 2*p - k) // s
y = torch.empty(N, C_out, Hp, Wp)
for i in range(Hp):
    for j in range(Wp):
        win = x_pad[:, :, i*s:i*s+k, j*s:j*s+k]          # (N, C_in, k, k)
        for n in range(N):
            y[n, :, i, j] = (W_ * win[n]).sum(dim=(1, 2, 3)) + b   # (C_out,)

# pooling: no parameters, every channel separately; window (N, C, k, k)
y_max[:, :, i, j] = win.reshape(N, C, -1).max(dim=2).values
y_avg[:, :, i, j] = win.mean(dim=(2, 3))                 # over HEIGHT and WIDTH
  • Conv backward (given in the assignment): weight_grad += win[n] * dup[n, :, i, j].view(-1, 1, 1, 1); dwin[n] += (W_ * dup[n, :, i, j].view(-1, 1, 1, 1)).sum(dim=0); bias_grad = dup.sum(dim=(0, 2, 3)). Use +=: windows overlap and weights are shared. Strip the padding from dx afterwards.
  • Max-pool backward: the gradient goes only to the arg max of each window.
  • First Linear after the convs: in_features = C_last * H'' * W'' (e.g. 16×16 input, 3×3 then 5×5 conv: 16 → 14 → 10, so C * 10 * 10).

7PyTorch with autograd

Model and training loop (Assignments 5, 8)
class Net(nn.Module):
    def __init__(self):
        super().__init__()                        # always first
        self.fc1 = nn.Linear(40, 200)             # __init__ CREATES layers
        self.fc2 = nn.Linear(200, 10)
    def forward(self, x):                         # forward USES them
        return self.fc2(F.relu(self.fc1(x)))

net = Net()
opt = torch.optim.Adam(net.parameters(), lr=1e-3)   # or SGD(..., momentum=0.9), RMSprop
crit = nn.CrossEntropyLoss()                         # takes LOGITS and class indices
for epoch in range(epochs):
    net.train()
    for xb, yb in train_loader:
        opt.zero_grad()                              # gradients accumulate otherwise
        loss = crit(net(xb), yb)                     # call net(x), not net.forward(x)
        loss.backward()
        opt.step()
    net.eval()                                       # batch norm / dropout in test mode
    with torch.no_grad():
        acc = (net(x_test).argmax(1) == y_test).float().mean()
  • nn.CrossEntropyLoss = log-softmax + NLL: don't put a softmax in the model's output.
  • SGD(momentum=0.9) sums gradients ($v=\rho v+g$), so its effective step is about 10× the slide version's.

past exam Average pooling forward (24/25)

Inside the loop over output positions, compute the average of each window for every sample and channel.

Show answer
window = x_padded[:, :, h_off:h_off + KS, w_off:w_off + KS]   # (N, C, KS, KS)
y[:, :, i, j] = window.mean(dim=(2, 3))                       # (N, C)

Flagged in the exam review: its answer writes window.mean(dim=1). That averages over the channels and returns shape (N, KS, KS), which doesn't even fit into y[:, :, i, j]. Pooling works per channel, over height and width: dims 2 and 3.

past exam Vanilla RNN forward (24/25)

Given x of shape (T, N, D), weights weight_xh, weight_hh and biases, loop over time and collect the hidden states.

Show answer
ht_1 = h0                                   # (N, H)
y = []
for t in range(T):
    xh = torch.addmm(self.bias_xh, x[t], self.weight_xh)   # b + x_t @ W_xh
    hh = torch.addmm(self.bias_hh, ht_1, self.weight_hh)   # b + h_{t-1} @ W_hh
    ht = torch.sigmoid(xh + hh)             # the review uses sigmoid; tanh is also common
    y.append(ht)
    ht_1 = ht
y = torch.stack(y)                          # (T, N, H)

The same weights are used at every time step (parameter sharing), so the number of parameters does not grow with the sequence length (another 24/25 question: "for longer sequences the number of parameters should increase": false). Theory and a GRU version: Week 6b.

One Adam step

Implement one Adam update for a parameter tensor w with state v, r, step counter t (starting at 1).

Show answer
v = rho1 * v + (1 - rho1) * g
r = rho2 * r + (1 - rho2) * g ** 2
v_hat = v / (1 - rho1 ** t)
r_hat = r / (1 - rho2 ** t)
w = w - lr * v_hat / torch.sqrt(r_hat + delta)

Check: at t = 1, v_hat = g and r_hat = g**2, so every weight moves by about lr.

Conv output size and parameters

Input (8, 3, 32, 32), Conv2d(3, 16, kernel_size=5, stride=1, padding=2), then max pool 2×2 stride 2. Output shape and number of conv parameters?

Show answer

Conv: $1+\lfloor(32+4-5)/1\rfloor=32$, so (8, 16, 32, 32); pool: $1+\lfloor(32-2)/2\rfloor=16$, so (8, 16, 16, 16). Parameters: $16\cdot3\cdot25+16=1216$.
