Bayes' rule and the Bayes decision

In one line

Posterior = likelihood × prior / evidence. Pick the class with the largest posterior.

Formulas
  • Bayes' rule: $P(\omega_i\mid x)=\dfrac{p(x\mid\omega_i)\,P(\omega_i)}{p(x)}$Posterior $P(\omega_i\mid x)$ · class density (likelihood) $p(x\mid\omega_i)$ · prior $P(\omega_i)$ · evidence $p(x)$.
  • Evidence (law of total probability): $p(x)=\sum_j p(x\mid\omega_j)\,P(\omega_j)$Each class density weighted by its prior. The posteriors then add up to 1.
  • Decision: pick $\arg\max_i\; p(x\mid\omega_i)\,P(\omega_i)$$p(x)$ is the same for every class, so you don't need it to decide. You only need it for the actual probability.
  • Numbers: $P(\omega_1)=0.3,\ P(\omega_2)=0.7$; $p(x\mid\omega_1)=0.6,\ p(x\mid\omega_2)=0.2$.$0.18$ vs $0.14$ → pick $\omega_1$. $p(x)=0.18+0.14=0.32$, so $P(\omega_1\mid x)=0.18/0.32=0.5625$.
Traps
  • Evidence = sum of the class densities ($0.6+0.2$). Wrong.Weight each density by its prior first. Check: the posterior must agree with the class you picked (> 0.5 for two classes).
  • "$p(x\mid\omega)$ is a probability, so it's ≤ 1." False.It is a density over $x$ and can be larger than 1. Only priors and posteriors live in $[0,1]$.

Sources: Week 1a §4, Bayes' rule

Squared error vs cross-entropy

In one line

Squared error (MSE) for regression. Cross-entropy for classification.

Why
  • Regression → MSE.The targets are continuous (prices, pixel values) and there is no sigmoid on the output, so the gradient $\hat y - t$ grows with the error.
  • Classification → cross-entropy.The output is a probability (sigmoid or softmax). Cross-entropy's gradient with respect to the logit is just $y - t$: big error, big step.
  • MSE + sigmoid stalls when the model is confidently wrong.$\partial L/\partial z = (y-t)\,y(1-y)$. A saturated sigmoid has slope $y(1-y)\approx 0$, so the gradient vanishes even though the error is large.
  • Numbers: $t=1$, $z=-5$: cross-entropy gradient $-0.99$, MSE gradient $-0.007$.About 150× bigger push from cross-entropy.
  • Same idea, different noise model.MSE is maximum likelihood with Gaussian noise. Cross-entropy is maximum likelihood with Bernoulli (two classes) or categorical (more classes) labels.
  • Example: MAE uses MSE.It reconstructs continuous pixel values (regression), computed only on the masked patches.
Traps
  • "MSE is a bad loss." False.It is only bad paired with a sigmoid on class labels. For continuous targets it is the standard choice.
  • "The gradient is small because the error is small." False.The error $y-t$ is large. It is the sigmoid slope $y(1-y)$ that is near 0.
  • "MSE fails for classification because it is non-convex." Incomplete.The main reason is the vanishing gradient. Non-convexity is a second one.

Sources: Week 3b §4, why cross-entropy · Week 8a §6, MAE

8aFoundation models open note →

ViT token shapes

In one line

Smaller patches give more tokens. The token length D never changes.

Why
  • Number of tokens: $N = HW/P^2$.Same image, smaller pieces, so more pieces. Halve $P$ → 4× more tokens, about 16× more attention weights (attention is $\propto N^2$).
  • D is fixed: a design choice.The residual connections ($x + \text{attn}(x)$), the position embeddings and the [class] token all need the same length.
  • Only the projection $\mathbf E \in \mathbb R^{P^2C\times D}$ changes shape.It turns a flattened patch of $P^2C$ numbers into a token of length $D$. Change $P$ or $C$ and E's number of rows changes; $D$ stays.
  • Grey → RGB: patches get 3× longer, tokens don't.The flattened patch is $P^2C$, so $C=3$ triples it. Same number of tokens, same $D$.
  • Count the [class] token: $\mathbf z_0$ is $(N+1)\times D$.ViT-Base/16 on 224×224 RGB: 196 + 1 tokens of length 768.
  • Position embeddings are added, not concatenated.So the shape stays $(N+1)\times D$.
  • Video: $N = \frac{T}{t}\cdot\frac{H}{P}\cdot\frac{W}{P}$.Tubelets of $t$ frames. Double $t$ → half the tokens, each flattened tubelet ($tP^2C$) twice as long, $D$ the same.
Traps
  • "Smaller patches give fewer tokens." False.$N = HW/P^2$: halving $P$ gives 4× more.
  • "RGB (or a different $P$) changes the token size." False.Only E's rows change. The token is still length $D$.
  • Forgetting $C$ in $P^2C$, or the +1 for [class].

Sources: Week 8a §4, ViT · Week 8a §5, video and other signals
