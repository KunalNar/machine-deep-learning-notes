Evaluation

A classifier is only as good as your estimate of its error. The training error is too optimistic; a test set is honest but noisy; cross-validation squeezes more out of a small data set. Learning and feature curves show where a classifier stands, and confusion matrices, reject curves and ROC curves show which mistakes it makes and what they cost.

0Test yourself first

Answer out loud before you read on. Each answer points to the part that explains it.

1. True or false (slide 1): the classification error on the training set is a good measure of the true classification error.
False. It is the apparent error, optimistically biased because the classifier was fitted to exactly those objects. A 1-NN classifier has 0 apparent error and can still be poor. → Part 3
2. Your classifier makes 10 errors on a test set of 100 objects. How precise is the estimate $\hat\varepsilon=0.10$?
Standard deviation $\sqrt{\varepsilon(1-\varepsilon)/N}=\sqrt{0.1\cdot0.9/100}=0.03$, so the true error is roughly $0.10\pm0.06$ (95%). A test set of 100 can't tell 8% from 12%. → Part 4
3. Two classifiers have the same overall error. Where can you see that they behave very differently?
In the confusion matrix: one may spread its mistakes evenly, the other may get a small class almost completely wrong. "Classification details are only observable in the confusion matrix" (slide 28). → Part 7

One sentence to remember

Never judge a classifier on the data it was trained on. Estimate the true error on independent data (or by cross-validation), remember that the estimate itself has a variance, and look beyond one number: per-class errors, rejects and ROC curves tell you what kind of mistakes it makes.

Why not optimise the classification error directly? It is piecewise constant in the parameters: gradient 0 almost everywhere (only the decision stump can minimise it, by exhaustive search; Week 3a). So we train on a convenient surrogate loss, and the optimum of the surrogate is probably not the optimum of the real loss (slide 6). That is why we must measure the error we care about separately.

3True error versus apparent error slides 7–9

Intuition

A student who memorises last year's exam answers scores 100% on that exam and still fails this year's. The training set is last year's exam: the classifier has adapted to it, noise included. The gap between the apparent error (on the training set) and the true error (on new data) is overfitting; it shrinks as the training set grows (slide 9).

  • True error $\varepsilon$: expected error on new objects from the same distribution. It decreases with the training-set size towards the best error that classifier type can reach.
  • Apparent error $\varepsilon_A$: error on the training set. It increases with the training-set size (more objects are harder to fit perfectly) towards the same limit from below.
  • A test set estimates the true error without bias, as long as it played no role in training or in any choice you made.

4The test set and the variance of the estimate slides 10–12

Formula (slide 11)

Each test object is a coin flip: wrong with probability $\varepsilon$. The number of errors in $N$ test objects is binomial, so

$$\hat\varepsilon=\frac{\#\text{errors}}N,\qquad\mathbb E[\hat\varepsilon]=\varepsilon,\qquad\sigma_{\hat\varepsilon}=\sqrt{\frac{\varepsilon(1-\varepsilon)}N}.$$

Training set versus test set size (slide 12)
  • A large training set gives a good classifier; a large test set gives a reliable error estimate. Usually there is only one design set to split.
  • Same set for training and testing: may give a good classifier, but the error estimate is optimistically biased.
  • Small independent test set: unbiased, but unreliable (large variance).
  • Large independent test set: unbiased and reliable, but for a badly trained classifier (too little left to train on).
  • 50–50 is a common compromise. "But is it really good?" Cross-validation does better.

5Cross-validation and leave-one-out slides 13–15, 24 Bishop §1.3

Intuition

Don't sacrifice data to a single test split; rotate. Every object gets tested exactly once, by a classifier that did not see it, and every object also helps to train the other rounds.

Formula
$$\hat\varepsilon_{\text{CV}}=\frac1n\sum_{i=1}^n\hat\varepsilon_i,\qquad\text{fold }i\text{: train on all folds except }i,\text{ test on fold }i.$$
  • Each round trains on a fraction $\frac{n-1}n$ of the data, so the estimate is slightly pessimistic for a classifier trained on everything; more folds = less pessimistic.
  • Leave-one-out ($n$ = number of objects) trains on $n-1$ objects each time: the least biased, "optimal" (slide 24), but $n$ trainings can be infeasible, and repeating it gives exactly the same answer.
  • 10-fold is the common compromise (slide 24). Repeating a random $n$-fold split and averaging reduces the variance from the split.
Choosing hyperparameters (24/25 exam)

Use three parts: train the models with different hyperparameters on the training set, select the best on the validation set (or by cross-validation within the training data), and report the error of that one final model on the untouched test set. If you pick the hyperparameter with the best test error, that test error is optimistically biased.

6Learning curves and feature curves slides 15–23

A learning curve plots the (estimated) error against the training-set size, usually both on the training set and on the test set (slide 16). It shows the amount of overtraining, whether more data would help, and how classifiers compare. It is not the training curve of gradient descent (loss against epochs): "how many epochs do we need?" can't be read from a learning curve (past exam).

  • More complex classifiers need larger training sets; so do larger feature sets (slides 17, 24).
  • Feature curves (slide 19): error against the number of features or the complexity; the optimum moves to more features when there is more training data. See Week 2b §9 for a simulated example.
  • Complexity example (slides 20–22): for a Parzen classifier the width $h$ is the complexity knob; small $h$ gives 0 training error and a high test error. See the density lab in Week 1b §10.
  • Curse of dimensionality (slide 23): the apparent error keeps falling with more features while the true error turns up again; the gap is the bias of the apparent error.

7Confusion matrices slides 25–28

Formula (slide 26)

With true labels $\lambda$ and assigned labels $l$: $c_{ij}=N\cdot P[l_j\mid\lambda_i]$ = the number of objects of true class $i$ that were assigned to class $j$. Rows: true class ("objects from"); columns: assigned class ("classified to"). The diagonal holds the correct decisions.

$$\text{overall error}=\frac{\sum_{i\neq j}c_{ij}}{\sum_{i,j}c_{ij}},\qquad\text{error in class }i=\frac{\sum_{j\neq i}c_{ij}}{\sum_jc_{ij}}.$$

The exam asks you to say how you define $c_{ij}$. The exam review answer uses the transposed convention ($c_{ij}=P(\text{predicted }i\mid\text{true }j)$, columns = true class). Both are fine as long as you state it.

Why one number is not enough (slide 28)

Slide 28 shows a classifier with overall error 0.15 whose matrix row for class A is $(1,9,0)$: 90% of class A is wrong, but A is small, so the overall error looks fine. Another classifier with overall error 0.30 spreads its mistakes evenly. Which is better depends on which mistakes matter, and only the confusion matrix shows it.

8Sensitivity, specificity, precision slides 35–38

Formula (slide 37; two classes, A = target)

As fractions of all objects: $\eta_A$ = class A assigned to A (correct), $\varepsilon_A$ = class A assigned to B, $\eta_B$ = class B assigned to B, $\varepsilon_B$ = class B assigned to A. So $p(A)=\eta_A+\varepsilon_A$, $p(B)=\eta_B+\varepsilon_B$, error $\varepsilon=\varepsilon_A+\varepsilon_B$ and accuracy $\eta=1-\varepsilon$.

$$\text{sensitivity (recall) of }A=\frac{\eta_A}{p(A)},\qquad\text{specificity}=\frac{\eta_B}{p(B)},\qquad\text{precision of }A=\frac{\eta_A}{\eta_A+\varepsilon_B}.$$

In true/false positive language: sensitivity = TP/(TP+FN), specificity = TN/(TN+FP), precision = TP/(TP+FP).

Tiny numbers: a medical test

1000 people, 100 of them ill (target class). The test finds 80 of the ill (20 missed) and wrongly flags 90 of the 900 healthy.

true \ test saysillhealthy
ill (100)TP = 80FN = 20
healthy (900)FP = 90TN = 810

Sensitivity $80/100=0.80$; specificity $810/900=0.90$; precision $80/170=0.47$ (more than half of the positive tests are false alarms); accuracy $890/1000=0.89$. A "test" that always says healthy scores accuracy 0.90, which is higher, with sensitivity 0. With unequal class sizes, accuracy alone misleads.

9The reject option slides 29–34

  • Outlier reject (slide 31): an object far from all training data; any label is a guess. Reject it.
  • Ambiguity reject (slide 32): an object near the boundary, where the posteriors are about equal. Reject it, and let a human or a better (more expensive) measurement decide.

The reject curve (slide 33): rejecting a band of width $2d$ around the boundary lowers the error from $\varepsilon_0$ to $\varepsilon_r$ at reject fraction $r$. Rejection also costs, so compare costs (slide 34):

Formula (slide 34)
$$c=c_r\,P(\text{reject})+c_\varepsilon\,P(\text{error})=c_r\,r+c_\varepsilon\,\varepsilon.$$

For a fixed total cost this is a straight line in the $(r,\varepsilon)$ plane with slope $-c_r/c_\varepsilon$. Shift it down until it just touches the reject curve: that tangent point is the cheapest operating point. With true posteriors the same rule reads: reject when $\max_kp(y_k\mid\mathbf x)<1-c_r/c_\varepsilon$ (see the reject widget in Week 1a §7).

10ROC curves and AUC slides 39–45

Intuition

A classifier usually outputs a score $S(\mathbf x)$ and a threshold $d$ turns it into a decision. Every threshold trades one error type for the other. The ROC curve draws all these trade-offs at once, so you can compare classifiers without committing to one threshold, prior or cost (slides 39–41).

  • Axes (slide 39): sensitivity (performance on the target class) against 1 − specificity (error on the non-targets). The slides also use the error–error version $(\varepsilon_A,\varepsilon_B)$.
  • Changing priors or costs (slide 42): the total error $P(A)\varepsilon_A+P(B)\varepsilon_B$ is a straight line in the $(\varepsilon_A,\varepsilon_B)$ plane; different priors give different slopes and so different best operating points on the same curve.
  • AUC (slide 43): the area under the curve. 1.0 is perfect, 0.5 is random guessing (the diagonal). It doesn't depend on the class priors.
  • Comparing and combining (slide 44): if no curve lies entirely below the other, the better classifier depends on the operating point. Any point on the line between two classifiers can be reached by randomly using one with probability α and the other with probability 1 − α.

11Conclusions slides 24, 45

Slides 24 and 45
  • Larger training sets give better classifiers; independent test sets are needed for unbiased error estimates; larger test sets give more accurate estimates.
  • Leave-one-out cross-validation is "optimal" but may be infeasible; 10-fold cross-validation is often used.
  • More complex classifiers and larger feature sets need larger training sets; small training sets need simpler classifiers or fewer features.
  • Reject to resolve ambiguity (objects near the boundary) and to cope with outliers.
  • Use ROC analysis for unknown or varying priors, and to compare and combine classifiers.

12Handwriting blueprint

Write each step on paper first, then reveal it.

1 · The variance of a test-set error estimate

  1. Each of the $N$ test objects is misclassified with probability $\varepsilon$, independently: the error count $k\sim\text{Binomial}(N,\varepsilon)$.
  2. $\mathbb E[k]=N\varepsilon$ and $\operatorname{Var}[k]=N\varepsilon(1-\varepsilon)$.
  3. $\hat\varepsilon=k/N$: $\mathbb E[\hat\varepsilon]=\varepsilon$ (unbiased) and $\operatorname{Var}[\hat\varepsilon]=\varepsilon(1-\varepsilon)/N$.
  4. Rough 95% interval: $\hat\varepsilon\pm2\sqrt{\hat\varepsilon(1-\hat\varepsilon)/N}$.

2 · Leave-one-out 1-NN from a distance matrix

  1. For object $i$, look at row $i$ and skip the diagonal (the object itself is left out).
  2. Find the smallest remaining distance: that is the nearest neighbour.
  3. Compare its label with $y_i$: count a mistake if they differ.
  4. Repeat for every row; $\hat\varepsilon_{\text{LOO}}=\#\text{mistakes}/n$. Watch for ties and say how you break them.

3 · From a confusion matrix to all the measures

  1. State the convention: rows = true class, columns = assigned class.
  2. Overall error = off-diagonal sum / total; per-class error = off-diagonal of row $i$ / row sum $i$.
  3. For a target class: TP = its diagonal cell, FN = rest of its row, FP = rest of its column, TN = everything else.
  4. Sensitivity TP/(TP+FN), specificity TN/(TN+FP), precision TP/(TP+FP), accuracy (TP+TN)/total.

4 · The optimal reject threshold

  1. Cost of rejecting $\mathbf x$: $c_r$. Cost of classifying it as the most probable class: $c_\varepsilon\,(1-\max_kp(y_k\mid\mathbf x))$.
  2. Reject when that is cheaper: $c_r<c_\varepsilon(1-\max_kp(y_k\mid\mathbf x))$.
  3. Equivalently: reject when $\max_kp(y_k\mid\mathbf x)<1-c_r/c_\varepsilon$.
  4. In the $(r,\varepsilon)$ plane: the operating point where the reject curve's slope equals $-c_r/c_\varepsilon$.

13Exam traps

Watch out
  • The apparent (training) error is optimistic; only data not used for training or for any choice gives an unbiased estimate.
  • A learning curve is error vs training-set size, not loss vs epochs. "How many epochs do we need?" is the question it can't answer (past exam).
  • Cross-validation estimates how a classifier generalises to an independent data set (past exam); it does not produce the final model.
  • Hyperparameters: train / validation / test (past exam). Tuning on the test set makes the test error optimistic.
  • Each fold trains on less data, so cross-validation is slightly pessimistic; LOO is the least biased.
  • σ of the error estimate is $\sqrt{\varepsilon(1-\varepsilon)/N}$: halving it needs four times as many test objects.
  • Overall error ≠ average of the class errors when classes have different sizes (slide 27: 0.233 vs 0.228).
  • Define your confusion-matrix convention (rows = true in the slides; the review answer uses columns = true).
  • Accuracy is misleading for imbalanced classes: check sensitivity, specificity and precision.
  • Precision depends on the class prior; the ROC curve and AUC do not.
  • AUC 0.5 = random, not "half right"; below 0.5 means the scores are inverted.
  • Rejecting costs too: choose the reject fraction by comparing $c_r$ with $c_\varepsilon$.
  • There is no single best classifier: learning curves cross (slide 18).

14Self-check

Answer first, then open. past exam marks questions from the 24/25 exam reviews.

1. past exam Which of these questions cannot be answered by looking at learning curves? (a) What is the performance on the test set? (b) How much training data is required? (c) How many epochs do we need? (d) Is the model overfitting?
(c). Epochs belong to the training curve of an optimiser, not to a learning curve, which has the training-set size on its x-axis.
2. past exam What best describes cross-validation?
A way to estimate how the classifier will generalise to an independent data set, by rotating which part of the data is held out.
3. past exam What is the most sensible approach for hyperparameter optimisation?
Split into training, validation and test sets. Train with different hyperparameters on the training set, select the best on the validation set, and evaluate only that final model on the test set.
4. past exam Which is true about true error, apparent error and generalisation error?
The review's answer: the generalisation error reflects performance on unseen data and is an estimate of the true error. Keep the distinctions clear: the apparent error is measured on the training set (optimistic); the error on unseen data estimates the true error.
5. past exam Leave-one-out 1-NN on six objects (three per class) from a distance matrix: what is the LOO error if exactly one object's nearest other object has the other label?
$1/6$. Work through every row as in Part 5.
