# Machine and Deep Learning: HTML study notes

Interactive exam-prep notes for the TU Delft course **Machine and Deep Learning** (2026). There is one self-contained HTML page per lecture, with diagrams, widgets you can play with, small worked examples, exam traps and self-check questions whose answers stay folded until you open them.

> These are unofficial student notes, written while studying. They can contain mistakes, so check against the slides and readings when in doubt. If you spot an error, open an issue or message me.

## How to use

1. **Get the files:** on GitHub click **Code → Download ZIP** and unzip it, or clone the repo:
   ```bash
   git clone https://github.com/KunalNar/machine-deep-learning-notes.git
   ```
2. **Open `Home.html`** in any browser (double-click it). It's the course map and exam hub: every note, plus past exam and assignment questions sorted by topic, each linked to the section that answers it.
3. You need an internet connection for the maths (KaTeX) and fonts, which load from a CDN.

Ticks you set on the Home page are saved in your own browser only, so nobody else sees them.

## Getting updates
