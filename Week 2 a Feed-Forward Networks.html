Feed-Forward Networks: Training with SGD, and XOR

The first deep-learning lecture. A feed-forward network (also called a multi-layer perceptron, MLP) is a chain of layers: each one takes a weighted sum of its inputs, adds a bias and applies a non-linear activation. Training repeats three steps: present a sample, compare the output with the label using a loss, and update every parameter a small step against its derivative. Doing that on small random minibatches is stochastic gradient descent. The XOR example shows why the activation matters: it lets the hidden layer learn its own features.

0Test yourself first

Answer out loud before you read on. Each answer points to the part that explains it.

1. Slide 2: inputs $x_1=1$, $x_2=0$; hidden nodes $g(x_1+x_2+0)$ and $g(x_1+x_2-1)$; output $g(1\cdot h_1-2\cdot h_2+0)$, with $g(z)=\max\{0,z\}$. What does the network output?
1. $h_1=g(1)=1$, $h_2=g(0)=0$, output $g(1-0)=1$. Try the other three inputs: you get 0, 1, 1, 0. That's XOR. → Part 3
2. True or false: two linear layers, without an activation in between, can solve XOR if the hidden layer is wide enough.
False. $\mathbf w^\top(\mathbf W^\top\mathbf x)=(\mathbf W\mathbf w)^\top\mathbf x$ is still one linear function of $\mathbf x$, whatever the width. You need a hidden layer and a non-linear activation (24/25 exam #44). → Part 9
3. Why does SGD compute the gradient on a few samples instead of on the whole training set?
Huge datasets make it impractical: one step with all $m$ samples needs $m$ gradient computations, so each step takes too long. A minibatch of $k$ samples gives a cheap, noisy estimate, and you can take $m/k$ steps for the price of one. → Part 7

One sentence to remember

A feed-forward network computes $\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c)$, then $y=\mathbf w^\top\mathbf h+b$; it is trained by repeating present → compare → update, where the update is $\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\,\frac1k\sum_{i=1}^k\nabla_{\boldsymbol\theta}L$ on a minibatch of $k$ samples (SGD). The non-linear $g$ is what lets the hidden layer learn new features, which is why XOR becomes solvable.

3What does this network output? slide 2 DL book 6, 6.1

Intuition

Every node does the same small job: multiply each incoming value by the weight on its arrow, add them up, add its own bias, then apply the activation $g$. The values flow from the inputs at the bottom to the output at the top, one layer at a time. Nothing flows back: that is what "feed-forward" means.

Tiny numbers: all four inputs
$(x_1,x_2)$$h_1=g(x_1+x_2)$$h_2=g(x_1+x_2-1)$output $g(h_1-2h_2)$
(0, 0)$g(0)=0$$g(-1)=0$0
(0, 1)$g(1)=1$$g(0)=0$1
(1, 0)$g(1)=1$$g(0)=0$1
(1, 1)$g(2)=2$$g(1)=1$$g(0)=0$

The outputs are 0, 1, 1, 0: this little network computes XOR. It is the same network as the XOR solution at the end of the lecture (Part 9).

Formula: one node
$$h_j=g\Big(\sum_i W_{ij}\,x_i+c_j\Big),\qquad y=g\Big(\sum_j w_j\,h_j+b\Big)\ \text{ (slide 2)},\qquad g(z)=\max\{0,z\}$$

$x_i$: input $i$ · $W_{ij}$: weight on the arrow from input $i$ to hidden node $j$ · $c_j$: bias of hidden node $j$ · $w_j$, $b$: output weights and bias. Slide 2 puts $g$ on the output too; slide 20 leaves the output linear, $y=\mathbf w^\top\mathbf h+b$. For XOR it makes no difference, because all four outputs are already $\ge0$.

In code (NumPy)
import numpy as np
relu = lambda z: np.maximum(0, z)
W = np.array([[1, 1], [1, 1]])     # column j = weights into hidden node j
c = np.array([0, -1])
w = np.array([1, -2]); b = 0
x = np.array([1, 0])
h = relu(W.T @ x + c)              # hidden layer
y = relu(w @ h + b)                # slide 2 also puts g on the output node
print(h, y)
# [1 0] 1

4Parameters, layers and depth slide 3 DL book 6 · UDL 3–4

The goal (slide 3)

There is some true function $f^*$ we would like to have, for example a perfect classifier $y=f^*(\mathbf x)$. We pick a network $y=f(\mathbf x;\boldsymbol\theta)$ and learn the parameters $\boldsymbol\theta$ so that $f(\mathbf x;\boldsymbol\theta)$ matches $f^*(\mathbf x)$ on the data.

Tiny numbers: how many parameters? (slide 3: 9)
PieceShapeCount
$\mathbf W=\begin{bmatrix}w_1&w_3\\w_2&w_4\end{bmatrix}$ (column $j$ feeds hidden unit $j$)$2\times2$4
$\mathbf c=(c_1,c_2)$, hidden biases$2$2

Length of $\boldsymbol\theta$9

The biases count. "6" (only the arrows) is the classic wrong answer.

Formula: one layer and its parameter count
$$\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c),\qquad \mathbf W\in\mathbb R^{n_{\text{in}}\times n_{\text{out}}},\ \mathbf c\in\mathbb R^{n_{\text{out}}}\quad\Rightarrow\quad n_{\text{in}}\,n_{\text{out}}+n_{\text{out}}\ \text{parameters}$$

A network's count is the sum over its layers: $2\to2\to1$ gives $(4+2)+(2+1)=9$; $2\to4\to4\to1$ gives $12+20+5=37$; $784\to100\to10$ (MNIST) gives $78{,}500+1{,}010=79{,}510$.

Slide 3 writes the row version $g(\mathbf x^\top\mathbf W+\mathbf c^\top)$, slides 19–20 the column version $g(\mathbf W^\top\mathbf x+\mathbf c)$: the same numbers, transposed. The assignments put a whole batch in the rows: $\mathbf H=g(\mathbf X\mathbf W+\mathbf b)$ with $\mathbf X\in\mathbb R^{N\times n_{\text{in}}}$.

A chain of functions slide 3

Notation clash with the DL book

The DL book (ch. 6) writes the same chain as $f(\mathbf x)=f^{(3)}(f^{(2)}(f^{(1)}(\mathbf x)))$ and calls $f^{(1)}$ the first layer. The slide numbers the other way round. The idea is the same in both: the innermost function runs first, and the depth is the number of functions in the chain. In an exam, answer with the slide's own formula in front of you.

In code: count parameters
def n_params(sizes):

5The training loop slides 4–11 DL book 4.3

  1. Present a training sample. Run $\mathbf x$ forward through the network (Part 3) and get the output.
  2. Compare the results. The slide only shows "??": we need a number that says how wrong the output is. That number is the loss.
  3. Update the parameters. Change $\boldsymbol\theta$ so that the loss goes down. That needs the derivative of the loss (Part 6).

Repeat while not converged: until the loss stops going down.

6Derivatives and gradient descent slides 12–13 DL book 4.3 · UDL 6.1

Intuition (slide 12)

Q: if I make a small change to $w$, how does $f(w)$ change? A: the derivative tells you. If the slope is positive, increasing $w$ increases the loss, so step left; if the slope is negative, step right. Q: how to reduce the loss? A: move in the opposite sign of its derivative.

Formula: the derivative as a local straight line (slide 12)
$$f(w+\epsilon)\approx f(w)+\epsilon\,f'(w),\qquad f'(w)=\frac{\partial f}{\partial w}$$

$\epsilon$ here is a small change in $w$. Choose $\epsilon=-\eta\,f'(w)$ with a small $\eta>0$: then $f$ changes by about $-\eta\,f'(w)^2\le0$. The loss goes down.

Formula: gradient descent on a whole network (slide 13)
$$L(\mathbf X,\mathbf y;\boldsymbol\theta)=\frac1n\sum_{i=1}^n\big(f(\mathbf x^{(i)};\boldsymbol\theta)-y^{(i)}\big)^2,\qquad \boldsymbol\theta^*=\boldsymbol\theta-\epsilon\,\nabla_{\boldsymbol\theta}L(\mathbf X;\mathbf y;\boldsymbol\theta)$$
  • $\mathbf X$: data matrix · $\boldsymbol\theta$: learnable parameters · $\mathbf y$: ground-truth vector (the labels) · $n$: number of samples. This $L$ is the mean squared error.
  • $\frac{\partial}{\partial\theta_k}L$: how a small change in the single parameter $\theta_k$ changes $L$.
  • $\nabla_{\boldsymbol\theta}L=\big(\frac{\partial L}{\partial\theta_1},\dots,\frac{\partial L}{\partial\theta_K}\big)$: the vector of all partial derivatives, one per parameter (9 for the slide 3 network).
  • $\boldsymbol\theta^*$: the updated parameters; $\epsilon$: the learning rate. Careful: on slide 13 $\epsilon$ is the learning rate, on slide 12 it was a small change.
Tiny numbers: gradient descent with one weight

One sample $x=1.5$ with label $y=3$, model $f=w\,x$, loss $L(w)=(1.5w-3)^2$, so $L'(w)=2\cdot1.5\,(1.5w-3)=4.5w-9$. Start at $w=0$ with $\epsilon=0.1$.

Check slide 12 first: $L(0)=9$, $L'(0)=-9$, so $L(0.1)\approx9+0.1\cdot(-9)=8.1$. Exactly: $(0.15-3)^2=8.1225$. Close.

7Stochastic gradient descent slides 14–15 DL book 5.9 · UDL 6.2

Formula: the loss and gradient on all samples (slide 14)
$$J(\boldsymbol\theta)=\frac1m\sum_{i=1}^m L(\mathbf x^{(i)},y^{(i)},\boldsymbol\theta),\qquad \nabla_{\boldsymbol\theta}J(\boldsymbol\theta)=\frac1m\sum_{i=1}^m\nabla_{\boldsymbol\theta}L(\mathbf x^{(i)},y^{(i)},\boldsymbol\theta)$$

The total loss is the average of the per-sample losses, so the gradient is the average of the per-sample gradients. $m$: number of training samples.

Why not use all samples? (slide 14)

Huge datasets make it impractical: one step takes too long. With a million images, gradient descent must push all of them through the network before it may move once. But the gradient is an average, and you can estimate an average well from a small random sample, just like a poll.

Formula: SGD update (slide 14)
$$\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\,\frac1k\sum_{i=1}^k\nabla_{\boldsymbol\theta}L(\mathbf x^{(i)},y^{(i)},\boldsymbol\theta)$$

The $k$ samples are a random minibatch. SGD computes exact gradients of a small number of samples $k$ and uses them to approximate the gradient of all samples. On average the minibatch gradient points the same way as the full gradient; each one is a bit off (noise).

Tiny numbers

$m=1{,}000{,}000$ training images, minibatch $k=100$. Gradient descent: 1 update per pass over the data. SGD: $m/k=$ 10,000 updates per pass (one epoch), each costing $1/10{,}000$ of a full-gradient step.

"This is the procedure we've already seen" (slides 14–15)

SGD is the training loop of Part 5: present (a minibatch), compare (the loss), update ($\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\cdot$gradient). Momentum, RMSprop and Adam improve the update step: Week 4a.

In code: same budget, three batch sizes (NumPy)
import numpy as np
rng = np.random.default_rng(0)
m = 1000                                          # training samples
x = rng.uniform(0, 2, m)
y = 1.0 * x + 0.5 + 0.1 * rng.standard_normal(m)  # truth: w = 1, b = 0.5

def loss(w, b):                                   # J(theta): MSE on ALL samples
    return np.mean((w * x + b - y) ** 2)

def grad(w, b, xb, yb):                           # gradient of the MSE on a batch
    e = w * xb + b - yb
    return 2 * np.mean(e * xb), 2 * np.mean(e)

def train(k, eps=0.3, budget=2000):               # budget: per-sample gradients we can afford
    w, b = -1.0, -1.0
    steps = budget // k
    for _ in range(steps):
        idx = rng.choice(m, size=k, replace=False)   # draw a minibatch of k samples
        gw, gb = grad(w, b, x[idx], y[idx])
        w, b = w - eps * gw, b - eps * gb            # theta* = theta - eps * gradient
    return steps, w, b, loss(w, b)

for k in [1000, 100, 10]:
    steps, w, b, L = train(k)
    print(f"k={k:4d}: {steps:3d} steps  w={w:.2f}  b={b:.2f}  J={L:.4f}")
# k=1000:   2 steps  w=0.70  b=0.38  J=0.2203
# k= 100:  20 steps  w=0.97  b=0.53  J=0.0108
# k=  10: 200 steps  w=1.00  b=0.51  J=0.0106

Every run computes 2,000 per-sample gradients (2 epochs). Full-batch gradient descent ($k=1000$) gets 2 updates and is still far off; SGD with $k=10$ gets 200 updates and reaches the noise floor ($J\approx0.01$, the variance of the noise in $y$).

8Why non-linear? Three ways to get φ slide 17 DL book 6 · UDL 4

The last layer is linear (slide 17)

Q: what is the equation of the last layer? A: let $\mathbf h=g(\mathbf x^\top\mathbf W+\mathbf c^\top)^\top$; the last layer is $\mathbf h^\top\mathbf w+b$. That is a linear model on top of $\mathbf h$. Linear is good (simple, easy to train) but possibly too rigid: it can only draw a line or a plane. So the work has to happen in what feeds it: we need a non-linear map $\phi$ of the input.

Formula (slide 17)
$$y=f(\mathbf x;\boldsymbol\theta,\mathbf w,b)=\phi(\mathbf x;\boldsymbol\theta)^\top\mathbf w+b$$

$\phi$: a non-linear feature map · $\mathbf w,b$: the linear last layer · $\boldsymbol\theta$: the parameters inside $\phi$ (in a network: the hidden layers).

WayExampleStrengthWeaknessSeen in
1 · $\phi$ = generic kernelRBF kernelVery flexible, convex trainingGeneric: says nothing about the task, so it often generalises poorly far from the training dataWeek 5a
2 · $\phi$ = hand-designed featuresSIFT for imagesUses expert knowledgeYears of human work per task; doesn't transferWeek 3a §3
3 · learn $\phi(\mathbf x;\boldsymbol\theta)$hidden layersFeatures fit the data and task; one recipe for every taskTraining is no longer convex; needs data and computethis course from here on

The strengths and weaknesses follow the DL book's chapter 6 introduction, which discusses exactly these three options.

9XOR: learning a representation slides 18–20 DL book 6.1 · UDL fig. 3.1 24/25 #44

Can a linear model learn XOR? slide 18

The problem (slide 18)

Inputs $\mathbb X=\{[0,0]^\top,[0,1]^\top,[1,0]^\top,[1,1]^\top\}$, labels $\mathbb Y=\{0,1,1,0\}$: the label is 1 when exactly one input is 1. Model: $f(\mathbf x;\mathbf w,b)=\mathbf x^\top\mathbf w+b$.

Why no line works, in four inequalities

Say class 1 means $\mathbf x^\top\mathbf w+b>t$ for some threshold $t$. Then:

  • $(0,1)$ and $(1,0)$ are class 1: $w_2+b>t$ and $w_1+b>t$. Add them: $w_1+w_2+2b>2t$.
  • $(0,0)$ and $(1,1)$ are class 0: $b<t$ and $w_1+w_2+b<t$. Add them: $w_1+w_2+2b<2t$.

Both can't be true. No $\mathbf w$, $b$, $t$ exist.

The fix: a hidden layer, with an activation slides 18–19

Formula (slides 18–19)

Add a hidden layer $\mathbf h=f^1(\mathbf x;\mathbf W,\mathbf c)$ and $y=f^2(\mathbf h;\mathbf w,b)$. Complete model: $f(\mathbf x;\mathbf W,\mathbf c,\mathbf w,b)=f^2(f^1(\mathbf x))$.

Q: should $f^1$ be linear? No. With $f^1(\mathbf x)=\mathbf W^\top\mathbf x$ and $f^2(\mathbf h)=\mathbf w^\top\mathbf h$:

$$f(\mathbf x)=\mathbf w^\top\mathbf W^\top\mathbf x=(\mathbf W\mathbf w)^\top\mathbf x\quad\text{: still one linear model, with weights }\mathbf W\mathbf w.$$

So make it non-linear with an activation function: $\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c)$, applied element-wise to each $h_i$. The slides use the rectified linear unit $g(z)=\max\{0,z\}$.

Past exam (24/25 #44)

"Which statement about the MLP network solving XOR is correct?" Both a hidden layer and non-linear activation functions are necessary. A hidden layer without $g$ collapses to a linear model; $g$ without a hidden layer, $g(\mathbf x^\top\mathbf w+b)$, still has a straight decision boundary.

The solution, checked slide 20

Tiny numbers: slide 20 in matrix form (one sample per column)

Full model $f(\mathbf X;\mathbf W,\mathbf c,\mathbf w,b)=\mathbf w^\top\max\{0,\mathbf W^\top\mathbf X+\mathbf c\}+b$ with

$$\mathbf W=\begin{bmatrix}1&1\\1&1\end{bmatrix},\quad\mathbf c=\begin{bmatrix}0\\-1\end{bmatrix},\quad\mathbf w=\begin{bmatrix}1\\-2\end{bmatrix},\quad b=0,\quad\mathbf X=\begin{bmatrix}0&0&1&1\\0&1&0&1\end{bmatrix}.$$ $$\mathbf W^\top\mathbf X=\begin{bmatrix}0&1&1&2\\0&1&1&2\end{bmatrix}\ \xrightarrow{+\mathbf c}\ \begin{bmatrix}0&1&1&2\\-1&0&0&1\end{bmatrix}\ \xrightarrow{\max\{0,\cdot\}}\ \begin{bmatrix}0&1&1&2\\0&0&0&1\end{bmatrix}\ \xrightarrow{\mathbf w^\top\cdot\,+\,b}\ \begin{bmatrix}0&1&1&0\end{bmatrix}$$

Exactly $\mathbb Y=\{0,1,1,0\}$. The ReLU only changes one number: the $-1$ of sample $(0,0)$ becomes 0. That one change is what makes the classes separable.

Set $c_2=0$: both hidden units become identical and the fold disappears. Set $w_2=-1$: $(1,1)$ flips to the wrong side.

10Recap

What to know for the exam (slide 22)
  • Feed-forward networks: a chain of layers $\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c)$, then $y=\mathbf w^\top\mathbf h+b$. Count parameters per layer as $n_{\text{in}}n_{\text{out}}+n_{\text{out}}$; depth = length of the chain.
  • How to train them with SGD: present → compare (loss) → update. $\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\,\frac1k\sum_{i=1}^k\nabla_{\boldsymbol\theta}L$ on minibatches of $k$ samples, because a full-gradient step on a huge dataset takes too long.
  • How representations are learned (XOR): a linear model can't solve XOR; stacked linear layers can't either; a hidden layer with an activation moves the points to a space where one line works.

Next for the deep-learning half: Week 3b answers the question this lecture leaves open: how do we compute $\nabla_{\boldsymbol\theta}L$ for every weight of a deep network? (Backpropagation.) It also explains why classification uses cross-entropy instead of squared error.

11Handwriting blueprint

Write each step on paper first, then reveal it.

1 · Forward pass of the slide 2 network, input (1, 1)

  1. Hidden sums: $z_1=1\cdot1+1\cdot1+0=2$, $z_2=1\cdot1+1\cdot1-1=1$.
  2. ReLU: $h_1=\max\{0,2\}=2$, $h_2=\max\{0,1\}=1$.
  3. Output: $g(1\cdot2-2\cdot1+0)=g(0)=0$.
  4. Label of $(1,1)$ in XOR is 0: correct.

2 · Count the parameters

  1. One layer from $n_{\text{in}}$ to $n_{\text{out}}$: a weight per pair, $n_{\text{in}}n_{\text{out}}$, plus a bias per output, $n_{\text{out}}$.
  2. Slide 3, $2\to2\to1$: $(2\cdot2+2)+(2\cdot1+1)=6+3=9$.
  3. 2025 coding task, $2\to4\to4\to1$: $12+20+5=37$.
  4. Activations (ReLU) have no parameters.

3 · Why no linear model solves XOR

  1. Suppose class 1 ⇔ $\mathbf x^\top\mathbf w+b>t$.
  2. Class 1 points: $w_2+b>t$ and $w_1+b>t$ ⇒ $w_1+w_2+2b>2t$.
  3. Class 0 points: $b<t$ and $w_1+w_2+b<t$ ⇒ $w_1+w_2+2b<2t$.
  4. Contradiction: XOR is not linearly separable. Best least-squares linear fit: $\mathbf w=\mathbf 0$, $b=\frac12$.

4 · Why two linear layers are one linear layer

  1. $f^1(\mathbf x)=\mathbf W^\top\mathbf x+\mathbf c$, $f^2(\mathbf h)=\mathbf w^\top\mathbf h+b$.
  2. $f(\mathbf x)=\mathbf w^\top(\mathbf W^\top\mathbf x+\mathbf c)+b=(\mathbf W\mathbf w)^\top\mathbf x+(\mathbf w^\top\mathbf c+b)$.
  3. That is $\mathbf x^\top\mathbf w'+b'$ with $\mathbf w'=\mathbf W\mathbf w$, $b'=\mathbf w^\top\mathbf c+b$: a linear model.
  4. So it fails on XOR, however wide the hidden layer. Fix: $\mathbf h=g(\mathbf W^\top\mathbf x+\mathbf c)$ with a non-linear $g$.

5 · Verify the XOR solution (slide 20)

  1. $\mathbf W^\top\mathbf X$: both rows are $x_1+x_2$: $\begin{bmatrix}0&1&1&2\\0&1&1&2\end{bmatrix}$.
  2. $+\mathbf c$: subtract 1 from the second row: $\begin{bmatrix}0&1&1&2\\-1&0&0&1\end{bmatrix}$.
  3. ReLU: $\begin{bmatrix}0&1&1&2\\0&0&0&1\end{bmatrix}$.
  4. $\mathbf w^\top\mathbf H+b$ = row 1 − 2·row 2 = $[0,1,1,0]$ ✓.

6 · One gradient-descent step

  1. $L(w)=(1.5w-3)^2$, so $L'(w)=2\cdot1.5\,(1.5w-3)=4.5w-9$.
  2. At $w=0$: $L=9$, $L'=-9$ (negative slope: move right).
  3. With $\epsilon=0.1$: $w^*=0-0.1\cdot(-9)=0.9$.
  4. New loss $(1.35-3)^2=2.72$: down from 9 ✓.

12Exam traps

Watch out
  • "A hidden layer is enough to solve XOR": false. You need the hidden layer and a non-linear activation (24/25 #44). Without $g$, $\mathbf w^\top\mathbf W^\top\mathbf x$ is linear.
  • "A non-linear activation is enough, no hidden layer needed": false. $g(\mathbf x^\top\mathbf w+b)$ with ReLU or sigmoid still splits the plane with one straight line.
  • Count the biases. The slide 3 network has 9 parameters, not 6.
  • Chain order: in $f^{(1)}(f^{(2)}(f^{(3)}(\mathbf x)))$ the first layer is $f^{(3)}$ (innermost). The DL book numbers the other way. Depth = length of the chain = 3.
  • Minus sign: $\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\nabla_{\boldsymbol\theta}L$. Moving with the gradient increases the loss.
  • $\epsilon$ means two things: a small change in $w$ on slide 12, the learning rate on slide 13.
  • SGD's gradients are exact, for the minibatch. They approximate the gradient of all samples (slide 14). Its noise comes from which samples were drawn, not from rounding.
  • SGD is not a different loss. It minimises the same $J(\boldsymbol\theta)$; it just estimates the gradient with $k$ samples instead of $m$.
  • Element-wise: $g$ acts on every $h_i$ separately; it is not a function of the whole vector.
  • Rows vs columns: the slides put one sample per column ($\mathbf W^\top\mathbf X$); the assignments put one per row ($\mathbf X\mathbf W$). Same $\mathbf W$ ($n_{\text{in}}\times n_{\text{out}}$), same numbers. PyTorch's nn.Linear stores the transpose, weight of shape $(n_{\text{out}},n_{\text{in}})$, which is why Assignment 2 copies weights with .t().
  • $\mathbf w=\mathbf 0$, $b=\frac12$ is not a bug: it is the best linear least-squares fit to XOR. "Everything $\frac12$" means "no idea".

13Self-check

Answer first, then open. past exam marks questions from the exam reviews.

1. past exam Which statement about the MLP network solving XOR is correct? (24/25 #44)
Both a hidden layer and non-linear activation functions are necessary to solve the XOR problem. See Part 9 and blueprint 4.
2. Assignment 2 builds Linear(3, 5) → ReLU → Linear(5, 4). How many parameters? What is the output shape for a batch of 2?
$(3\cdot5+5)+(5\cdot4+4)=20+24=$ 44; ReLU adds none. Output shape (2, 4): the batch dimension stays.
3. What does a partial derivative $\frac{\partial}{\partial\theta_k}L(\mathbf X;\mathbf y;\boldsymbol\theta)$ represent? And the gradient?
How a small change in the single parameter $\theta_k$ changes $L$. The gradient $\nabla_{\boldsymbol\theta}L$ is the vector of all partial derivatives, one per parameter (slide 13).
4. $L(w)=4$ and $L'(w)=-2$. Estimate $L(w+0.1)$. Which way should gradient descent move $w$?
$L(w+0.1)\approx4+0.1\cdot(-2)=3.8$. The slope is negative, so increasing $w$ lowers the loss: move $w$ up (right).
5. What does $\boldsymbol\theta^*=\boldsymbol\theta-\epsilon\nabla_{\boldsymbol\theta}L(\mathbf X;\mathbf y;\boldsymbol\theta)$ do?
It updates the parameters with gradient descent: every parameter takes a step of size $\epsilon$ (the learning rate) times its partial derivative, against the slope.
6. $m=50{,}000$ training images, minibatch $k=100$. How many SGD updates per epoch? How many for full-batch gradient descent?
$m/k=500$ SGD updates per epoch; full-batch gradient descent makes 1.
7. What does $b=\frac12$, $\mathbf w=[0,0]$ do on XOR, and why is it a natural answer?
It predicts $\frac12$ for every input (MSE 0.25). It is the least-squares optimum of the linear model: with no line able to separate the classes, the best the linear model can do is predict the average label.
8. $f^1(\mathbf x)=\mathbf W^\top\mathbf x$ and $f^2(\mathbf h)=\mathbf w^\top\mathbf h$. What is $f(\mathbf x)$ and why is that a problem?
$f(\mathbf x)=\mathbf w^\top\mathbf W^\top\mathbf x=(\mathbf W\mathbf w)^\top\mathbf x$: one linear model. Extra linear layers add parameters but no expressive power; the activation $g$ is needed.
9. For $f(\mathbf x)=f^{(1)}(f^{(2)}(f^{(3)}(\mathbf x)))$: first layer, output layer, depth?
First layer $f^{(3)}$, second (hidden) $f^{(2)}$, output $f^{(1)}$, depth 3 (slide 3).
10. Name the three ways to get a non-linear $\phi$ (slide 17). Which one is deep learning?
(1) a generic kernel such as RBF, (2) hand-designed feature extractors such as SIFT, (3) learn $\phi(\mathbf x;\boldsymbol\theta)$. Deep learning is (3): it learns the representation.
11. In the XOR solution, which single number does the ReLU change, and why does that matter?
The $-1$ in $\mathbf W^\top\mathbf X+\mathbf c$ for sample $(0,0)$ becomes 0. Before it, the four points lie on one line with class 1 in the middle; after it, $(0,0)$ leaves that line and $h_1-2h_2=\frac12$ separates the classes.
12. Why does the second training sample on the slides ($-1.2$ vs label 0) call for a bigger update than the first ($0.8$ vs 1)?
Its squared error is $1.44$ versus $0.04$, and the gradient of the squared error, $2(\text{output}-\text{label})$, is $-2.4$ versus $-0.4$ (in magnitude 6 times larger). Bigger mistakes give bigger steps.

The 2025 coding exam builds an MLP $2\to4\to4\to1$ with ReLU after the first two linear layers. (a) How many parameters? (b) For a batch of $N=8$ samples in the rows, give the shape of every intermediate tensor. (c) Which tensors have no parameters?

Show worked solution

  • (b) $\mathbf X$ $(8,2)$ → $\mathbf z_1$ $(8,4)$ → $\mathbf h_1=\mathrm{ReLU}(\mathbf z_1)$ $(8,4)$ → $\mathbf z_2$ $(8,4)$ → $\mathbf h_2$ $(8,4)$ → output $(8,1)$.

E2 · XOR forward in NumPy, samples in rows

Write the slide 20 network for a data matrix X of shape (4, 2) with one sample per row, as in the assignments. Check that it returns [0 1 1 0].

Hint

Transpose the slide formula: $(\mathbf W^\top\mathbf X)^\top=\mathbf X^\top\mathbf W$. With samples in rows the product is X @ W, and the bias is added to every row by broadcasting.

Show worked solution
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])   # one sample per ROW
W = np.array([[1, 1], [1, 1]])                    # (n_in, n_out) = (2, 2)
c = np.array([0, -1])                             # broadcast over the 4 rows
w = np.array([1, -2]); b = 0
H = np.maximum(0, X @ W + c)                      # (4, 2)
print(H @ w + b)
# [0 1 1 0]

$\mathbf W$ is symmetric here, so forgetting the transpose would go unnoticed. With a non-symmetric $\mathbf W$ it wouldn't: always write the shapes down.

E3 · One SGD step by hand

Take the XOR network of slide 20, but with a wrong output bias $b=0.3$. Present the single sample $\mathbf x=(0,1)$, label $y=1$, with loss $L=(\hat y-y)^2$. (a) Compute $\hat y$ and $L$. (b) Compute $\frac{\partial L}{\partial b}$ and $\frac{\partial L}{\partial\mathbf w}$. (c) Take one SGD step ($k=1$) with $\epsilon=0.25$ on $b$ and $\mathbf w$. What is the new output for this sample? (d) What happens to the output for $(1,1)$?

Hint

$\hat y=\mathbf w^\top\mathbf h+b$, so $\frac{\partial\hat y}{\partial b}=1$ and $\frac{\partial\hat y}{\partial\mathbf w}=\mathbf h$. Chain rule: multiply by $\frac{\partial L}{\partial\hat y}=2(\hat y-y)$.

Show worked solution
  • (a) $\mathbf h=\max\{0,(1,1-1)\}=(1,0)$. $\hat y=1\cdot1-2\cdot0+0.3=1.3$; $L=(0.3)^2=0.09$.
  • (b) $\frac{\partial L}{\partial\hat y}=2(1.3-1)=0.6$. So $\frac{\partial L}{\partial b}=0.6$ and $\frac{\partial L}{\partial\mathbf w}=0.6\,\mathbf h=(0.6,\,0)$.
  • (c) $b^*=0.3-0.25\cdot0.6=0.15$; $\mathbf w^*=(1-0.25\cdot0.6,\ -2-0)=(0.85,\,-2)$. New output: $0.85\cdot1-2\cdot0+0.15=1.0$: the loss on this sample is now 0.
  • (d) For $(1,1)$, $\mathbf h=(2,1)$: before $2-2+0.3=0.3$, after $0.85\cdot2-2+0.15=-0.15$. One update for one sample also moves the other outputs. That is why SGD averages over minibatches and needs many steps.

$\frac{\partial L}{\partial w_2}=0$ because $h_2=0$: a weight whose input is 0 doesn't affect this output, so it gets no update. Computing such derivatives for every layer is backpropagation, Week 3b.

2025 coding E E4 · A minibatch SGD loop

For the linear model $wx+b$ with MSE (data as in Part 7, $m=1000$), write sgd_epochs(x, y, k, eps, epochs): every epoch, shuffle the samples once, walk through them in minibatches of $k$, and take one SGD step per minibatch. Print $w$, $b$ and the full-data loss $J$ after every epoch. Use $k=10$, $\epsilon=0.3$, 3 epochs, start $(w,b)=(-1,-1)$.

Hint

rng.permutation(m) gives a shuffled index order; slice it as perm[start:start + k]. The MSE gradient on a batch is $\frac{\partial}{\partial w}=2\,\overline{e\,x}$, $\frac{\partial}{\partial b}=2\,\overline{e}$ with $e=wx+b-y$.

Show worked solution
def sgd_epochs(x, y, k=10, eps=0.3, epochs=3, seed=1):
    rng = np.random.default_rng(seed)
    w, b = -1.0, -1.0
    m = len(x)
    for ep in range(epochs):
        perm = rng.permutation(m)                  # shuffle once per epoch
        for start in range(0, m, k):
            idx = perm[start:start + k]            # next minibatch of k samples
            e = w * x[idx] + b - y[idx]            # errors on the minibatch
            gw, gb = 2 * np.mean(e * x[idx]), 2 * np.mean(e)
            w, b = w - eps * gw, b - eps * gb      # theta <- theta - eps * grad
        J = np.mean((w * x + b - y) ** 2)
        print(f"epoch {ep + 1}: {m // k} steps, w={w:.3f}, b={b:.3f}, J={J:.4f}")
    return w, b
# epoch 1: 100 steps, w=1.001, b=0.488, J=0.0106
# epoch 2: 100 steps, w=0.937, b=0.463, J=0.0221
# epoch 3: 100 steps, w=1.020, b=0.518, J=0.0122

After one epoch it is already at the minimum ($J\approx0.01$). Then $J$ jumps around (0.0106 → 0.0221 → 0.0122): with a constant learning rate SGD keeps jittering around the minimum, because every minibatch gradient is slightly different. A smaller $\epsilon$, a bigger $k$, or a learning rate that decays over time settles it (Week 4a). The 2025 coding task does the same with model.parameters() and torch.optim.SGD.
